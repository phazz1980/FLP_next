# Сборка и прошивка

Редактор генерирует скетч Arduino C++ и собирает его через `arduino-cli` с ядром `esp32:esp32`. Для заливки нужен USB-кабель; плата ESP32 DevKit подключается как COM-порт.

## Что нужно установить

- `arduino-cli` ищется по порядку: переменная `FLP_ARDUINO_CLI`, папка программы, `PATH`, `Program Files\Arduino CLI`.
- Ядро ESP32 ищется в папке `esp32core` рядом с программой, затем в системной папке данных arduino-cli (`%LOCALAPPDATA%\Arduino15`).
- Если `arduino-cli` не найден, при запуске редактор предложит скачать фиксированные версии: arduino-cli 1.5.1 в папку программы и ядро ESP32 3.3.12 в `esp32core` (несколько сотен МБ). Скачанный arduino-cli проверяется по контрольной сумме.
- Если `arduino-cli` есть, а ядра нигде нет, первая сборка скачает его в `esp32core`. Для этого у папки программы должны быть права на запись.
- Библиотеки, которые требуют блоки (например, для DS18B20 или DHT22), `flp build` ставит сам.

Если чего-то нет, сборка остановится с понятным сообщением, а остальная работа редактора не пострадает.

## Меню «Проект»

| Пункт | Что делает |
| --- | --- |
| Проверить (F7) | проверяет схему без сборки |
| Код C++ | показывает сгенерированный скетч, с отладкой или без неё |
| Собрать (F5) | генерирует и собирает прошивку |
| Пересобрать полностью | собирает заново, даже если схема не менялась: нужно после обновления библиотек или ядра ESP32 |
| Залить на плату | собирает, если нужно, и прошивает по выбранному порту |

**Язык комментариев скетча.** В редакторе он следует за языком интерфейса: русский интерфейс — русские комментарии, любой другой — английские (в `project.toml` это `comment_lang = "en"`, пусто — русский; редактор обновляет значение сам). Комментарии внутри шаблонов блоков и сообщения об ошибках не переводятся. В командной строке язык можно переопределить: `flp gen --lang en`.

Кнопка 🛠 «С отладкой» в заголовке окна включает в прошивку модуль онлайн-отладки. Он нужен, чтобы видеть живые значения: [отладка](help:debug).

## Фоновая сборка

Программа заранее собирает проект в фоне с низким приоритетом и держит постоянную папку сборки для каждого проекта (`.flp/<проект>/`). Поэтому повторная сборка после небольшой правки идёт быстро.

## Командная строка

Те же действия доступны без редактора:

```bash
flp check examples/pump
flp gen examples/pump
flp build examples/pump
flp upload examples/pump
```

`flp gen --stdout` печатает скетч в консоль, `flp build --debug` собирает с модулем отладки, `flp monitor` показывает живые значения. Папку библиотеки можно задать переменной `FLP_LIBRARY`.

`flp upload-wasm модуль.wasm --port COM3 --allow gpio_write,millis` заливает один WASM-модуль на плату с мастер-прошивкой (раздел «WASM-модули на плате» спецификации `specs/wasm-on-mcu`): модуль заменяется на ходу, остальные модули и выходы не сбрасываются. Имя берётся из `--name`, из `module.toml` рядом с файлом или из имени файла; права на железо — из `--allow` или `module.toml`.

`flp gen-wasm проект [--sheet N] [--upload] [--port COM3]` собирает листы схемы как WASM-модули: один лист — один модуль, файлы `.flp/<проект>/wasm/<имя листа>/<имя>.wasm` и `module.toml`. С `--upload` модули сразу заливаются на плату с мастер-прошивкой (без полной прошивки, остальные модули не останавливаются). Поддержаны блоки логики, таймеры, математика, переменные и выводы GPIO/АЦП/ШИМ платы; в `module.toml` права `allow` перечисляют ровно используемое железо. Блок, которого в модуле нет (сеть, шины, расширители), даёт ошибку с его именем: такой лист собирается обычным скетчем. Переменные, общие для нескольких листов, и связи между листами ходят через теги мастера. Подтяжка входа и режим пина мастер ставит сам; ШИМ передаётся в 8 битах (0…255).

## Откуда берётся код блока

Порядок такой: шаблон `esp32.cpp.tmpl` в папке блока; если его нет — встроенный блок на Rust (логика, таймеры, счётчик, математика, биты и слова, текст, ПИД, выводы, датчики, расширители PCF8574, UART и Modbus, сеть и веб-интерфейс); если и его нет — `block.wasm`; иначе генерация сообщает, что у блока нет кода для прошивки.

## Блоки на WASM

Блок без шаблона C++, но с `block.wasm`, перед генерацией переводится в C программой `w2c2` (путь: настройки редактора, `FLP_W2C2` или `PATH`). Если `w2c2` не найден, генерация говорит, какой блок нельзя перевести. Подробности — в справке «Редактор блока».

## Если не собирается

Смотрите панель сообщений и раздел [частые ошибки](help:errors). Первая сборка после установки ядра может занять несколько минут: это нормально.
