# Сборка и прошивка

Редактор генерирует скетч Arduino C++ и собирает его через `arduino-cli` с ядром `esp32:esp32`. Для заливки нужен USB-кабель; плата ESP32 DevKit подключается как COM-порт.

## Что нужно установить

- `arduino-cli` должен быть доступен программе (в `PATH`).
- Ядро ESP32: `arduino-cli core install esp32:esp32`.
- Библиотеки, которые требуют блоки (например, для DS18B20 или DHT22), `flp build` ставит сам.

Если чего-то нет, сборка остановится с понятным сообщением, а остальная работа редактора не пострадает.

## Меню «Проект»

| Пункт | Что делает |
| --- | --- |
| Проверить (F7) | проверяет схему без сборки |
| Код C++ | показывает сгенерированный скетч, с отладкой или без неё |
| Собрать (F5) | генерирует и собирает прошивку |
| Пересобрать полностью | собирает заново, даже если схема не менялась: нужно после обновления библиотек или ядра ESP32 |
| Залить на плату | собирает, если нужно, и прошивает по выбранному порту |

Флажок «С отладкой» включает в прошивку модуль онлайн-отладки. Он нужен, чтобы видеть живые значения: [отладка](help:debug).

## Фоновая сборка

Программа заранее собирает проект в фоне с низким приоритетом и держит постоянную папку сборки для каждого проекта (`.flp/<проект>/`). Поэтому повторная сборка после небольшой правки идёт быстро.

## Командная строка

Те же действия доступны без редактора:

```bash
flp check examples/pump
flp gen examples/pump
flp build examples/pump
flp upload examples/pump
```

`flp gen --stdout` печатает скетч в консоль, `flp build --debug` собирает с модулем отладки, `flp monitor` показывает живые значения. Папку библиотеки можно задать переменной `FLP_LIBRARY`.

## Если не собирается

Смотрите панель сообщений и раздел [частые ошибки](help:errors). Первая сборка после установки ядра может занять несколько минут: это нормально.
