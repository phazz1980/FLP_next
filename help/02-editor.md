# Редактор

Раскладка: сверху заголовок окна с меню ☰ и кнопками, слева дерево проекта и теги, справа библиотека блоков и вкладка ИИ, в центре платы-листы, внизу сообщения и монитор порта.

Заголовок окна свой: слева иконка и кнопка ☰, в ней все меню (Файл, Примеры, Вид, Правка, Проект, Библиотека, Справка); свободное место в заголовке можно тянуть мышью, двойной щелчок разворачивает окно; справа стоят название программы и кнопки окна. Полный экран (F11) закрывает и панель задач. При закрытии программа запоминает положение, размер и состояние «развёрнуто» окна и восстанавливает их при следующем запуске.

## Кнопки в заголовке

Кнопки подписаны только значками; название появляется во всплывающей подсказке.

| Кнопка | Действие |
| --- | --- |
| 💾 | сохранить проект |
| ↶ ↷ | отменить и повторить |
| название платы | настройки МК: плата, режим подключения, порты |
| 🔌 и ↻ | выбрать порт платы и найти порты заново |
| ✔ | проверить схему |
| `</>` | показать сгенерированный код C++ |
| 🔨 | собрать прошивку |
| ⬆ | собрать и залить на плату |
| ⏹ | остановить сборку или заливку |
| 🛠 | собирать «С отладкой» (с модулем онлайн-отладки) |
| 🔗 | подключиться к уже прошитой плате |

Залить отладочную прошивку и сразу подключиться можно в меню «Проект → Отладка: залить и подключиться».

Во время отладки добавляются: ⏹ — остановить отладку, 🔓 — снять форсировки, 📊 — значения, ⏱ — время цикла. Свободное место в заголовке можно тянуть мышью, чтобы двигать окно.

## Проект и файл

Проект — один файл `.crab` (ZIP-архив). Внутри лежат настройки (`project.toml`), логика (`logic.toml`), координаты блоков (`layout.toml`) и картинка плат `boards.pdf`, которая пересоздаётся при сохранении. Логика хранится отдельно от координат, поэтому перетаскивание блоков не меняет саму схему.

«Файл → Открывать .crab двойным щелчком» привязывает расширение к программе. «Файл → Автосохранение» включает периодическое сохранение. Старый формат (папка с теми же TOML-файлами) тоже читается.

## Платы-листы

Схема разбита на листы (платы). Лист можно переименовать, удалить, поменять местами с соседним, отключить и свернуть. Перед удалением программа спрашивает подтверждение (удаление можно отменить), а после перемещения активной остаётся перемещённая плата, и полотно прокручивается вместе с ней: она остаётся под курсором, и кнопку ▲ или ▼ можно нажимать подряд. Кнопка добавления листа находится над листами. Отключённый лист не попадает в прошивку. Правая кнопка мыши на листе открывает меню, где есть вырезание, копирование и вставка блоков.

## Горячие клавиши

| Клавиши | Действие |
| --- | --- |
| Ctrl+S | сохранить |
| Ctrl+Shift+S | сохранить как |
| Ctrl+Z | отменить |
| Ctrl+Y или Ctrl+Shift+Z | повторить |
| Delete | удалить выделенное |
| Ctrl+X, Ctrl+C, Ctrl+V | вырезать, копировать, вставить |
| F1 | справка; с выбранным блоком — его страница |
| F5 | собрать |
| F7 | проверить схему |
| F11 | на весь экран и обратно |

Отменять можно и правки, сделанные ИИ-помощником: каждая его правка — один шаг отмены.

В любом текстовом поле правая кнопка мыши открывает меню «Вырезать», «Копировать», «Вставить»; вырезать и копировать доступны, когда текст выделен. Текст, выделенный мышью в справке, журнале, сообщениях и чате ИИ, копируется так же: правая кнопка по выделению — «Копировать» (или Ctrl+C).

## Дерево и теги

Слева находятся дерево проекта и теги: входы, выходы, переменные и темы MQTT. Вход или выход создаётся кнопкой «+» у группы, но на лист не попадает: как переменную и тему MQTT, его нужно перетащить на лист, и он станет блоком. Двойной щелчок по входу, выходу или переменной открывает их свойства. Одиночный щелчок находит их блок на листе и выделяет его; повторный щелчок по той же строке переходит к следующему экземпляру — следующей копии входа или выхода, следующему блоку переменной (по листам, сверху вниз и слева направо). Строка дерева подсвечена, пока выделен любой её экземпляр. Вход или выход, уже стоящий на плате, можно перетащить ещё раз — появится его копия (`кнопка_2`, `кнопка_3`…). Копия — тот же тег: вывод и настройки у всех копий общие, в дереве одна строка, свойства копии открывают тег. Связи у каждой копии свои. Копия входа выдаёт то же значение, что тег; если подключено несколько копий выхода, на вывод попадает последняя по порядку выполнения. Если удалить с листа сам тег, его имя и место займёт первая копия. Удаление последнего экземпляра с листа не удаляет вход или выход: он остаётся в дереве и, как неиспользуемая переменная, подсвечивается жёлтым с пометкой «(не используется)». Такой выход не попадает в скетч, и проверка не ругает его пустой вход. Совсем убрать вход или выход из проекта можно правой кнопкой по нему в дереве — «Удалить из проекта». Переменную можно читать на любой плате сколько угодно раз, а записывать только в одном месте. Если её никто не записывает, она работает как уставка.

## Настройки

«Проект → Настройки МК...» выбирает плату, режим подключения и порты. Для USB скорость фиксирована и ничего настраивать не нужно. «Проект → Конструктор веб-интерфейса...» собирает страницу, которую плата отдаёт по Wi-Fi.

## Обновления и отчёты

Галочка «Справка → Получать бета-версии» включает в проверку пробные версии (пререлизы на GitHub): они выходят раньше обычных и могут быть нестабильны. В меню «Справка» есть «Проверить обновления», «Что нового в этой версии» и «Сообщить об ошибке» — форма, которая открывает заполненный issue на GitHub.
