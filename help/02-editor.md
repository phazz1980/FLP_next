# Редактор

Раскладка похожа на FLProg: сверху меню и панель сборки, слева дерево проекта и теги, справа библиотека блоков и вкладка ИИ, в центре платы-листы, внизу сообщения и монитор порта.

## Проект и файл

Проект — один файл `.flpn` (ZIP-архив). Внутри лежат настройки (`project.toml`), логика (`logic.toml`), координаты блоков (`layout.toml`) и картинка плат `boards.pdf`, которая пересоздаётся при сохранении. Логика хранится отдельно от координат, поэтому перетаскивание блоков не меняет саму схему.

«Файл → Открывать .flpn двойным щелчком» привязывает расширение к программе. «Файл → Автосохранение» включает периодическое сохранение. Старый формат (папка с теми же TOML-файлами) тоже читается.

## Платы-листы

Схема разбита на листы (платы). Лист можно переименовать, удалить, поменять местами с соседним, отключить и свернуть. Кнопка добавления листа находится над листами. Отключённый лист не попадает в прошивку. Правая кнопка мыши на листе открывает меню, где есть вырезание, копирование и вставка блоков.

## Горячие клавиши

| Клавиши | Действие |
| --- | --- |
| Ctrl+S | сохранить |
| Ctrl+Shift+S | сохранить как |
| Ctrl+Z | отменить |
| Ctrl+Y или Ctrl+Shift+Z | повторить |
| Delete | удалить выделенное |
| Ctrl+X, Ctrl+C, Ctrl+V | вырезать, копировать, вставить |
| F1 | справка; с выбранным блоком — его страница |
| F5 | собрать |
| F7 | проверить схему |

Отменять можно и правки, сделанные ИИ-помощником: каждая его правка — один шаг отмены.

## Дерево и теги

Слева находятся дерево проекта и теги: переменные и темы MQTT. Тему MQTT можно перетащить на лист, и она станет блоком. Переменную можно читать на любой плате сколько угодно раз, а записывать только в одном месте. Если её никто не записывает, она работает как уставка.

## Настройки

«Проект → Настройки МК...» выбирает плату, режим подключения и порты. Для USB скорость фиксирована и ничего настраивать не нужно. «Проект → Конструктор веб-интерфейса...» собирает страницу, которую плата отдаёт по Wi-Fi.

## Обновления и отчёты

В меню «Справка» есть «Проверить обновления», «Что нового в этой версии» и «Сообщить об ошибке» — форма, которая открывает заполненный issue на GitHub.
