# Частые ошибки

Здесь собраны сообщения проверки схемы (F7) и типичные проблемы сборки. Ссылки «Что это?» из окна проверки пока не готовы: сообщения ядра не имеют кодов, поэтому ищите свою ошибку по тексту.

## Проверка схемы

| Сообщение | Что значит и что делать |
| --- | --- |
| недопустимый id блока | в id только буквы, цифры, «_» и «-», без пробелов и точек; переименуйте блок |
| id встречается дважды | два блока с одним id; переименуйте один |
| неизвестный тип | такого блока нет в библиотеке; проверьте имя или «Библиотека → Перечитать блоки» |
| у типа нет параметра | параметр удалён или назван иначе; откройте свойства блока |
| не задан параметр | заполните обязательный параметр, например номер вывода |
| параметр меньше или больше допустимого | значение вне границ; поправьте |
| константа на входе не подходит к типу | тип константы и порта различаются; задайте константу того же типа |
| нет блока или порта в связи | связь ведёт в удалённый блок или порт; удалите её или соедините заново |
| это выход, а связь должна вести во вход | связь соединена задом наперёд |
| на вход уже подан другой источник | на вход можно подать один источник; уберите лишнюю связь |
| вывод GPIO уже занят | два блока используют один вывод; выберите другой |
| вывод GPIO занят флеш-памятью | эти выводы у ESP32 заняты внутренней памятью; выберите другой |
| может быть в проекте только один | блок вроде Wi-Fi или NTP допускается один раз |
| инвертировать можно только логический | инверсия есть только у логических портов |
| переменная объявлена дважды, недопустимое имя | поправьте имя переменной |
| пароль или имя сети | пароль Wi-Fi 8–63 символа, имя сети не длиннее 32 байт |

## Сборка

| Проблема | Что делать |
| --- | --- |
| `arduino-cli` не найден | установите его и добавьте в `PATH` |
| нет ядра `esp32:esp32` | `arduino-cli core install esp32:esp32` |
| не хватает библиотеки | `flp build` ставит недостающие; проверьте интернет |
| после обновления странные ошибки | «Проект → Пересобрать полностью» |
| порт занят | закройте монитор порта и другие программы, работающие с платой |
| плата не отвечает при заливке | попробуйте другой кабель; на некоторых платах при заливке нужно держать кнопку BOOT |

## Если ничего не помогло

«Справка → Сообщить об ошибке» открывает форму; приложите текст сообщения и проект. Как устроена сборка, описано в разделе [сборка и прошивка](help:build).
