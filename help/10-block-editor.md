# Редактор блока

Открывается через «Библиотека → Новый блок...» или правой кнопкой на блоке в библиотеке («Посмотреть / Изменить блок...»). Встроенные блоки открываются только для просмотра — кнопка «Создать копию» делает из него свой блок. Свой блок сохраняется в `user_library/` и появляется в библиотеке сразу, без перезапуска.

Вверху окна — как блок выглядит на плате (картинка обновляется по мере правок) и общие поля, ниже — вкладки.

## Общие поля

- **Название** — как блок называется в библиотеке. Тип блока в схеме берётся из названия при первом сохранении и потом не меняется.
- **Обозначение** — короткая надпись на самом блоке (`TON`, `&`, `a + b`).
- **Где лежит** — набор, раздел или папка в библиотеке; для нового блока выбирается из списка.
- **Хранит состояние** — блок помнит значения между циклами (таймеры, триггеры, счётчики); обратные связи допустимы только через такие блоки.
- **Один на проект** — такой блок в проекте может быть только один (Wi-Fi, NTP).
- **Библиотеки** — библиотеки Arduino для `arduino-cli` через запятую, можно с версией: `OneWire@2.3.8`. Недостающие сборка ставит сама.

## Входы и выходы

Имя порта — буквы (можно русские), цифры и `_`, без пробелов. По имени порт связан в схеме и в коде. Входы, выходы и параметры не могут называться одинаково, имена `id` и `type` заняты. При переименовании порта ссылки на него в шаблоне кода обновляются сами.

Типы: `bool`, `int`, `float`, `string`; у входа ещё `any` (любой) и `number` (любое число). Неявно приводится только `int` → `float`.

- **Если не подключён** (только входы) — значение входа, к которому ничего не подключено. Для `bool` выбирается из списка: `true`, `false` или «обязателен». Пусто или «обязателен» — вход обязательно надо подключить, иначе проверка схемы сообщит об ошибке.
- **Условие when** — порт есть на блоке, только пока условие верно; см. ниже.
- **Описание** — подсказка при наведении и строка в справке по блоку.

Стрелки двигают строку, ✕ удаляет её.

## Условие when

Условие делает порт или параметр необязательным: он появляется на блоке, только когда условие истинно. Пусто — «всегда».

Условие — выражение Jinja, то же, что в `{% if %}` шаблона. Переменные в нём — **параметры этого же блока**; других имён нет (проверка скажет «нет такого параметра»). Значения: `bool` — `true`/`false`, `int` и `float` — числа, строка и выбор — строки, время (`1s`, `500ms`) — миллисекунды.

| Условие | Когда порт или параметр есть |
|---|---|
| `count >= 3` | параметр `count` не меньше 3 (так в блоке И растёт число входов) |
| `mode == "input"` | выбран режим «input» |
| `use_reset and time > 1000` | включён `use_reset` и время больше секунды |

Пока условие ложно, порта нет, подключить к нему связь нельзя, а скрытый вход не требует подключения. Скрытые параметры не учитываются при подсчёте занятых пинов. Если условие записано с ошибкой, порт считается включённым, а ошибку покажет проверка схемы. Параметр не может зависеть в условии от самого себя.

## Параметры

Параметры задаются в свойствах блока, а не подключаются проводами.

- **Вид**: `bool`, `int`, `float`, `string`, `duration` (время: `1s`, `500ms`) и `pin` (вывод платы; рядом выбирается режим).
- **По умолчанию** — пусто значит «обязателен»: без значения проверка сообщит об ошибке.
- **Мин., Макс.** — границы для чисел.
- **Условие when** — параметр показывается, только пока оно верно.
- **Под блоком** — что писать под блоком на листе: `имя=значение`, только значение, пароль со звёздочками или ничего.

## Код ESP32

Над шаблоном поле **Заголовки**: файлы для `#include` через запятую (`DHT.h, Wire.h`).

Шаблон кода Arduino C++ (язык шаблонов — minijinja), с подсветкой: ключевые слова, типы, числа, строки, комментарии и `#include` раскрашены, подстановки `{{ … }}` и `{% … %}` и маркеры разделов `// @setup` выделены своими цветами. Подстановки:

- `{{ input.имя }}` — значение входа, `{{ output.имя }}` — переменная выхода, `{{ param.имя }}` — параметр как литерал C++;
- `{{ id }}` — id блока в схеме (им начинают имена своих переменных и функций);
- `{% if value.имя %}…{% endif %}` — код, который попадёт в скетч только при нужном значении параметра.

Шаблон делится на разделы: `// @global` — переменные блока, `// @setup` — код в `setup()`, `// @loop` — код цикла, `// @functions` — функции. С пометкой `once` (`// @global once`) раздел попадёт в скетч один раз на все блоки. Кнопки «Вставить» над полем кладут нужную подстановку на место курсора. Русские имена портов в коде превращаются в латинские идентификаторы сами.

## Описание

Текст `docs.md` в Markdown: что делает блок и пример. Показывается в этой справке на странице блока; справа от поля — предпросмотр.

Над полем — кнопки шаблонов: **Ж** (жирный), **К** (курсив), `код`, заголовки H1–H3, списки, цитата, блок кода, таблица и ссылка. Кнопка оборачивает выделенный текст (без выделения вставляет заготовку и выделяет её, чтобы сразу печатать поверх). Списки, цитата и заголовок работают со строками выделения, повторное нажатие снимает разметку.

«Картинка...» берёт файл png, jpg, gif или bmp и вставляет строку `![описание](images/имя.png)`. При сохранении блока файл копируется в папку `images/` блока и едет вместе с ним в `.crabblock`; картинки, которых больше нет в тексте, из папки убираются. Картинка занимает строку целиком; показывается в предпросмотре и в справочнике блоков.

## Библиотека и пример

Библиотеки Arduino, которые блок принесёт с собой. При «Прикрепить библиотеку...» её главный заголовок (`<имя>.h` или единственный `.h` в `src/`) сам попадает в поле «Заголовки» на вкладке «Код ESP32», а при «Убрать» — исчезает оттуда. Если заголовка с таким именем нет, впишите его вручную. Здесь же пример проекта `example.flpn` (копируется при сохранении). Они попадают и в файл `.crabblock` при обмене блоками.
