# Библиотека блоков

Каждый блок — папка `library/<тип>/` с тремя файлами: `block.toml` (название, группа, входы, выходы, параметры), `esp32.cpp.tmpl` (шаблон кода Arduino C++) и `docs.md` (описание и пример). Новый блок появляется без перекомпиляции программы.

## Встроенные и пользовательские

Встроенные блоки идут с программой и открываются только для просмотра. Пользовательские лежат в папке `user_library/` рядом с `library/`. Пользовательский блок не может занять тип встроенного: такой блок пропускается с предупреждением. В библиотеке справа две вкладки: «Встроенные» и «Пользовательские».

## Свой блок

«Библиотека → Новый блок...» открывает редактор блока. В нём видно, как блок выглядит на плате, и есть вкладка «Пробная генерация». Правая кнопка на блоке даёт «Посмотреть / Изменить блок...», «Новый блок на основе этого...» и для своих блоков «Удалить блок...». Блок можно создать и словами через [ИИ-помощника](help:ai).

Если вы поменяли файлы блока вручную, выберите «Библиотека → Перечитать блоки»: справочник блоков в справке обновится тоже.

## Обмен блоками

Блок можно сохранить в один файл `.flpblock` и отдать другому пользователю; в файл попадают подключаемые библиотеки Arduino и пример. Несколько блоков собираются в набор `.flpblocks` с одной версией, автором и контактами. Создание, импорт и экспорт наборов есть в окне библиотеки, а в командной строке работают `flp export` и `flp import`.

## Справка по блокам

Описание блока берётся из его `docs.md`. Если файла нет, справка покажет порты и параметры из `block.toml`. Весь список с группами — в [справочнике блоков](help:blocks).

Формат `block.toml` подробно описан в файле `library/README.md` в репозитории.
