# Kincony KC868-A6

Контроллер на ESP32 с шестью реле, шестью оптоизолированными входами, аналоговыми входами
и выходами, RS-485 и шиной SPI. **Ethernet в этой версии платы нет** — сеть только по Wi-Fi.

> **Не проверено на железе.** Таблица выводов и адреса микросхем собраны по описанию
> производителя и обсуждениям на форумах. У разных ревизий платы они могут отличаться
> (в одних источниках шина I²C — GPIO4/GPIO15, в других — GPIO26/GPIO23). Перед первой
> заливкой сверьтесь с документацией своей платы и поправьте таблицу в «Библиотека →
> Изменить плату».

## Что на плате

| Что | Где | Как использовать |
|---|---|---|
| Реле K1–K6 | PCF8574, адрес 0x24, на шине I²C (SDA = GPIO4, SCL = GPIO15) | блок «Kincony KC868-A6: Реле» |
| Входы X1–X6 | PCF8574, адрес 0x22, на той же шине | блок «Kincony KC868-A6: Входы» |
| Аналоговые входы A1–A4 | GPIO36, GPIO39, GPIO34, GPIO35 | блок «Аналоговый вход» |
| Аналоговые выходы DA1, DA2 | GPIO26, GPIO25 | блок «Аналоговый выход» (ЦАП) |
| Выводы под датчики IO-1, IO-2 | GPIO32, GPIO33 | 1-Wire (DS18B20), DHT и т. п. |
| RS-485 | RX = GPIO14, TX = GPIO27 | блоки Modbus RTU |
| SPI | CLK = GPIO18, MOSI = GPIO23, MISO = GPIO19, CS = GPIO5 | |

Реле и входы работают через расширители, поэтому им не нужны выводы ESP32: блоки платы
сами знают адрес микросхемы и выводы шины, а полярность (реле включаются нулём, активный
вход читается нулём) уже учтена.

## Заливка

Плата определяется как «ESP32 Dev Module» (`esp32:esp32:esp32`). Для заливки подключите её
по USB; если плата не входит в режим прошивки сама, зажмите кнопку BOOT.

## Картинки

Схемы и фотографии можно положить в папку `images/` и вставить в этот текст в редакторе
платы: «Библиотека → Изменить плату → Описание → Картинка…».
