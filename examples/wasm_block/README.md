# Модуль симуляции блока на WASM

Блок «Фильтр сглаживания» (`lowpass`): `block/` — сам блок с готовым `block.wasm`,
`rust/` и `cpp/` — исходники модуля, `build.ps1 rust|cpp` пересобирает `block/block.wasm`.

Чтобы попробовать, скопируйте папку `block/` в свой набор под именем типа:
`user_library/Мои блоки/lowpass/` (имя папки обязано совпадать с `type` в `block.toml`).
Дальше — редактор блока, вкладка «Пробный прогон»; после пересборки модуля скопируйте
новый `block.wasm` в ту же папку, окно перезагрузит его само.
