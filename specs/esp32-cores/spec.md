# Ядра для разных ESP32 (скачивание в настройках)

## Цель
Дать пользователю скачивать ядро/инструменты отдельно для каждого чипа (ESP32, ESP32-S3, ESP32-C3)
и не давать выбрать плату, чьё ядро ещё не скачано. Базовый пакет остаётся небольшим,
Xtensa-S3 и RISC-V-C3 докачиваются по желанию.

## Что есть сейчас
- Чипы в программе: `esp32`, `esp32s3`, `esp32c3` (+ Super Mini); список плат — `BOARDS`, `BOARD_MODELS`,
  пользовательские платы (`boardcfg.rs`, меню «▾» у поля FQBN).
- Ядро ищется в `esp32core` рядом с .exe, затем в `%LOCALAPPDATA%\Arduino15` (`flp-build`, `has_core`).
- Готовые пакеты на странице релиза v1.2.0: toolchain-esp32 (ESP32), addon-s2s3 (S2/S3), addon-riscv (C3/C5/C6/H2/P4).

## Сценарии
1. В настройках программы есть раздел «Ядра ESP32»: по строке на чип, статус «установлено / нет»
   (проверка по папкам: `esp32core` и `Arduino15` — есть ли компилятор и `*-libs` этого чипа),
   кнопка «Скачать» с прогрессом и «Обновить статус».
2. В выборе платы чипы без ядра показаны серыми и не выбираются; в подсказке — «ядро не скачано, см. Настройки».
3. Проект, чья плата без ядра, открывается, но сборка даёт понятное сообщение со ссылкой на настройки.
4. Ядро, положенное пользователем в папку вручную (распаковка пакета), определяется при «Обновить статус»/запуске.

## Критерии готовности
- Проверка наличия по файлам папок, без запуска arduino-cli; тест на временной папке для трёх чипов.
- Недоступная плата не выбирается в меню; поле FQBN вручную тоже не принимает чип без ядра (предупреждение).
- Скачивание пакета чипа распаковывает его в `esp32core` и после этого чип становится доступным без перезапуска.
- Справка `help/05-build.md`, `help/08-errors.md` обновлена.

## Вне задачи
- Чипы S2, C5, C6, H2, P4 (в программе их нет); AVR и STM32; обновление версии ядра.

## Ответы
1. Качаем готовые пакеты с релиза GitHub (.7z), распаковка встроенная (крейт sevenz-rust), проверка SHA-256.
2. Классический ESP32 — базовый пакет `toolchain-esp32` (arduino-cli и ядро); сборка ESP32 без ядра по-прежнему может поставить его через arduino-cli.
3. Пакеты по чипам: `core-esp32s3`, `core-esp32c3` (компилятор RISC-V и libs C3). Для ручной установки на релизе есть ещё `core-esp32s2` и `core-riscv-extra` (C5/C6/H2/P4), программа их не качает.
