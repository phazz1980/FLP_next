# План: ядра по чипам

- `flp-build/src/cores.rs`: список пакетов (`PACKS`), проверка по папкам (`installed_in`, `is_installed`, `fqbn_available`),
  скачивание с прогрессом и отменой, SHA-256, распаковка 7z в папку программы. `ensure_core` для S3/C3 без пакета
  возвращает понятную ошибку вместо скачивания всего ядра через arduino-cli.
- `flp-editor/src/coresconf.rs`: окно «Файл → Ядра ESP32...» (статус, «Скачать», прогресс, «Обновить статус»).
- `boardcfg.rs`: плата чипа без ядра в списке серая, под полем FQBN — предупреждение.
- Релиз v1.2.0: пакеты `FLP_next-toolchain-esp32`, `-core-esp32s3`, `-core-esp32c3`, `-core-esp32s2`, `-core-riscv-extra`.
- Риски: размер C3 (~330 МБ); права записи в папку программы; не проверено скачивание в живой программе.
