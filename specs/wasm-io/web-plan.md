# Веб в модулях: план

## Затронуто
- `specs/wasm-on-mcu/proto/master/master.ino`: секция `FLP_WEB` — реестр виджетов (как `FlpUiItem` в скетче), обработчики `/`, `/ui/layout`, `/ui/state`, `/ui/set` на `FLProgWebServer`; операции `net` 17–22.
- `crates/flp-build/src/master.rs`: признак `web`; страница (`flp_blocks::device_page()`) подставляется в мастер как `PROGMEM`-константа при сборке, чтобы не дублировать HTML в `master.ino`.
- `crates/flp-codegen/src/wasm/web.rs` (новый): `web_ui` и виджеты — регистрация при старте, значения каждый шаг.
- `crates/flp-sim/src/mcu.rs`: заглушка операций + тест.
- `examples/web_wasm`, `help/05-build.md`, `docs.md` виджетов.

## Операции `net` (черновик)
- 17: настройки страницы — a = код (1 заголовок, 2 страницы, 3 фон, 4 пароль, 5 «Система», 63 готово), b, c — строка (указатель, длина) или число.
- 18: регистрация виджета: a — указатель на запись (вид, подпись, единицы, колонка, строка, ширина, высота, страница, точность, от, до, шаг, цвет, фон); возвращает индекс.
- 19: показать числом: a = индекс, b = значение (f32); 20: показать строкой: a, b, c = указатель, длина.
- 21: прочитать число: a = индекс (значение, которое записала страница); 22: прочитать строку: a, b, c.

## Риски
- Размер мастера: измерить до и после; запас у C3 — около 37% раздела.
- Гонки между задачей модуля и сетевой задачей: значения в критической секции (как слоты MQTT).
- Строки виджетов в модуле до 128 байт.
