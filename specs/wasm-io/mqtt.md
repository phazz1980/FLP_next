# MQTT в модулях WASM (задача 6)

## Цель
Блоки `mqtt`, `mqtt_publish`, `mqtt_subscribe` работают в модуле WASM. Клиентом и сокетом владеет мастер
(один клиент на плату, поверх Wi-Fi или Ethernet), модуль настраивает его, отправляет значения и читает
принятые. Строка идёт от UART через `text_*` до брокера и обратно.

## Сценарии
1. `mqtt` с брокером/портом/логином/паролем, выходы `connected` и `error`.
2. `mqtt_publish`: значение bool/int/float/строка в топик по фронту `en`, по изменению или периодически, `retain`.
3. `mqtt_subscribe`: топик (с `+` и `#`), тип значения string/int/float/bool, выходы значения и `received`.
4. Клиент работает через интерфейс, выбранный параметром `net` (как у `ntp`); сеть может быть любой из двух.
5. Схема без MQTT собирается в мастер без кода клиента (флаг `CRAB_MQTT`).

## Критерии готовности
- Публикация и подписка в модуле ведут себя как C++-блоки (триггеры, deadband, decimals, retain, `received` на один шаг).
- Тест в `crab-sim` (заглушка): настройки уходят мастеру, публикация и приём проходят через `mqtt`.
- Мастер с `CRAB_MQTT` собирается для ESP32 и C3; размер записан.
- Пример в `examples/`, `docs.md` блоков, `help/05-build.md`. Не проверено на железе — пишем явно.

## Вне задачи
Веб и OTA (задача 7), Modbus TCP, TLS и QoS выше 0, STM32.

## Вопросы
1. Пароль MQTT: как у Wi-Fi — попадает в данные модуля при заливке (в файл проекта не пишется)?
2. Топик публикации и подписки — константа в параметре; нужен ли топик из строкового входа (во время работы)?
3. Подписок на плату: сколько держит мастер (по умолчанию 4, как `max_subscriptions`), и разные модули могут подписываться на один топик?
4. Размер сообщения: строки в модулях ограничены 128 байтами, пакет клиента 768 — оставляем 128 для строк?

## Решения
(ответы пользователя, 04.11.2026)
1. Пароль MQTT, как у Wi-Fi, попадает в данные модуля при заливке, в файл проекта не пишется.
2. Топик — константа в параметре, плюс необязательный строковый вход `topic`: подключён — берётся из него (у `mqtt_publish` и `mqtt_subscribe`, в C++-выводе тоже).
3. Подписок на плату `max_subscriptions` (по умолчанию 4, память по требованию, библиотека уже умеет); разные модули могут подписываться на один топик, мастер раздаёт сообщение всем подписавшимся.
4. Строки в модулях остаются до 128 байт; длиннее — обрезается (пакет клиента 768).
