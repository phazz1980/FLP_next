# Сеть в модулях: план (задача 5)

## Подход
Мастер хранит интерфейс `FlprogOnBoardWifi` и NTP-сервис из FLProg_Network (те же вызовы, что в C++-выводе).
Модуль не трогает сеть сам: вызовы `net` только записывают запрос в общую структуру `g_net`
(состояние радио, строки настроек), а задача `hardware` применяет запрос, вызывает `pool()` и
обновляет снимок (готовность, статус, ошибка, IP, время). Так нет гонки между модулем и сетевой задачей.

## ABI: `net(op, a, b, c, d) -> i32` (право `net`, бит 2048)
- op 0: число. a — код (1 dhcp, 2 период NTP в мс, 3 режим-сервер NTP включён), b — значение; a = 63 — применить настройки (один раз).
- op 1: строка настройки: a — код (1 ssid, 2 password, 3 ip, 4 gateway, 5 subnet, 6 ap_ssid, 7 ap_password, 8 NTP-сервер), b — указатель, c — длина.
- op 2: состояние радио: a = 0 выключено, 1 клиент, 2 точка, 3 оба.
- op 3: чтение Wi-Fi: a — поле (0 клиент готов, 1 точка готова, 2 статус, 3 ошибка, 4 IP клиента или точки как uint32).
- op 4: чтение NTP: a — поле (0 есть время, 1 возраст в с, 2 час, 3 минута, 4 секунда, 5 день, 6 месяц, 7 год, 8 день недели 1..7, 9 Unix UTC), b — смещение в секундах (зона + лето).
- op 5: время текстом «ЧЧ:ММ:СС»: a — указатель, b — ёмкость, c — смещение; возвращает длину.
Адрес текстом модуль получает из IP (op 3, поле 4) через `text` op 11.

## Затронутые файлы
- `master.ino`: секция `FLP_NET`, `P_NET`, `h_net`, задача `hardware`.
- `flp-build/master.rs`: `MasterFeatures.net`, библиотеки из `libs/` передаются и для сети.
- `flp-codegen/src/wasm/net.rs` (новый): блоки `wifi` и `ntp`; `HW_NET` в `HW_NAMES`.
- `flp-sim/src/mcu.rs`: заглушка `net` (настройки, поля, время), тест с `compare`.
- `examples/net_wasm`, `docs.md` блоков `wifi`/`ntp`, `help/05-build.md`.

## Риски
- Сборка мастера с FLProg_Network (размер flash/RAM): проверяем на C3 и ESP32.
- `ethernet` (W5500) и режим «Ethernet» у `ntp` — отдельным шагом 5b; пока ошибка с именем блока.
- Вход `mode` и `en` блока `wifi` читаются каждый шаг; настройки со входов (runtime) — только константы проекта.
