# Веб-интерфейс в модулях WASM

## Цель
Страница управления (`web_ui` и веб-виджеты) работает на плате с мастер-прошивкой, как в C++-скетче:
виджеты показывают сигналы схемы и дают уставки, кнопки, переключатели и ввод текста.

## Сценарии
1. Схема на листе с `wifi` (`web = true`), `web_ui` и виджетами заливается модулем (📦). Адрес платы открывает ту же страницу, что и у скетча.
2. Ползунок, кнопка, переключатель и ввод меняют выходы виджетов в модуле; индикаторы, значения, шкалы и тексты показывают входы.
3. Ввод текста (например, имя сети) возвращается модулю строкой и доходит до `wifi`/`mqtt` через вход параметра.

## Вне задачи
- OTA убрана совсем (решение 04.11.2026): мастер собирается без второго слота прошивки, параметры `web_update`, `ota`, `ota_password` удалены из блоков `wifi` и `ethernet`, раздел загрузки прошивки — со страницы «Система».
- Заливка модулей по Wi-Fi — отдельный вопрос, см. ниже.

## Критерии готовности
- [ ] Страница из `examples/web_wasm` открывается на плате и работает — не проверено на железе (мастер собирается, проверка `flp check` и симулятор проходят).
- [x] Значения виджетов доходят до модуля и обратно (`web_page_goes_through_the_master`); 0,5 с на плате — не проверено.
- [x] Мастер с веб-сервером влезает в 2 МБ раздела; размер записан в `network-tasks.md`.
- [x] Симулятор: заглушка веб-операций, тест обмена значениями.
- [x] Справка и `docs.md` виджетов актуальны (включая график, «Система» и форму сети).

## Вопросы
Ответы (04.11.2026):
1. Сервер — `FLProgWebServer` (единственный, что работает и по Wi-Fi, и по W5500); размер измеряем, при необходимости сжимаем страницу.
2. Схема: движок страницы вшит в мастер (флаг `FLP_WEB`), описание виджетов и значения приходят из модуля; страница ходит только к мастеру.
3. `web_ui` и виджеты — на одном листе, остальные листы общаются через теги.
4. Пароль страницы — в данных модуля при заливке, защищает чтение и запись (как в скетче).
5. Первый шаг — виджеты, `/ui/state`, `/ui/set`, `/ui/layout`. `hist` (графики), `web_net` и страница «Система» — вторым шагом, если первый влезает по размеру.
6. Заливка модулей по Wi-Fi — вне этой задачи.
