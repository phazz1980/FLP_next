# Версии для Linux и Android

## Цель
Пользоваться CrabLogic не только на Windows: на Linux — полный редактор со сборкой и заливкой;
на Android — приложение, которое открывает проект, симулирует схему и по USB-OTG подключается
к плате для онлайн-отладки и заливки.

## Сценарии
1. Linux: скачал `tar.gz` из релиза, распаковал, запустил редактор; открыл проект, собрал и залил
   прошивку на ESP32 через `arduino-cli`, подключился к плате для отладки.
2. Android: поставил APK, открыл `.flpn` (из файлов или по ссылке), увидел схему, запустил симуляцию.
3. Android: подключил плату кабелем OTG, подключился к уже залитой прошивке, видит живые значения,
   меняет уставки и форсирует входы.
4. Android: залить прошивку без ПК. **Вне первой очереди** — см. «Вне задачи».

## Критерии готовности
- Linux: GitHub Actions собирает `tar.gz` с редактором и `flp` под x86_64; в архиве нет
  зависимостей, кроме системных (GTK не нужен, окно через X11/Wayland от winit).
- Linux: все `cfg(windows)`-места имеют рабочую замену (пути данных, запуск `arduino-cli`
  без окна консоли, ассоциация файлов, самообновление — выключено или своё).
- Android: APK из `cargo-apk`/`xbuild` запускается на реальном телефоне (arm64), показывает
  схему и симулирует её.
- Android: отладка по USB-OTG работает через собственный транспорт (USB Host API, CDC/CP210x/CH340),
  кадры и CRC те же, что в `flp-debug`.
- Справка (`help/`) описывает обе платформы.

## Вне задачи
- Сборка прошивки на Android (нет `arduino-cli`, нужен весь тулчейн). Идея на потом: собирать
  на ПК/в облаке, на телефон отдавать готовый `.bin`.
- Wi-Fi-отладка (отдельная задача из плана), macOS, iOS, Linux arm.
- Магазин приложений, подпись релизного APK (пока подпись отладочным ключом).

## Открытые вопросы
- Какие USB-мосты у ваших плат: CP210x, CH340, родной USB ESP32-S3? От этого зависят драйверы
  в Android-части.
- Есть ли реальный Android-телефон для проверки и какая версия (минимум Android 8?).
- Linux: какой дистрибутив у вас (Ubuntu/Debian/Fedora/…)? Проверка в Actions идёт на Ubuntu.
