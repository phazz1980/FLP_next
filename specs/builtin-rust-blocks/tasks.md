# Задачи: встроенные блоки на Rust

- [x] 1. Крейт `crab-blocks`: `Ctx`, `Behavior` и реализации переезжают из `crab-sim::builtin`; `crab-sim` берёт их оттуда.
      *Проверка:* `cargo test -p crab-sim` без изменений в тестах.
- [x] 2. Трейт `BuiltinBlock`, `CppCtx`, `CppParts`, `get(kind)`; в `render_block` ветка «нет шаблона → Rust-блок».
      *Проверка:* юнит-тест: блок с шаблоном берёт шаблон, без шаблона — Rust, без обоих — прежняя ошибка.
- [x] 3. Пилот: `add`, `not`, `timer_on`, `counter`, `and` (переменное число входов) — `emit_cpp`, шаблоны удалены.
      *Проверка:* снимки `crab-codegen` побайтно те же.
- [x] 4. `simsrc`: обёртка модуля симуляции принимает готовые части; тест сравнения C++ ↔ Rust для пилотных блоков.
      *Проверка:* `CRAB_ZIG=… cargo test --test builtin_cpp` — выходы совпали; без zig пропуск.
- [x] 5. Остальные блоки группами: логика и триггеры; фронты, таймеры, `pulse`, `generator`, `debounce`;
      сравнение и математика; `switch`, `mux`, `constant`, `scale`, `limit`, `hysteresis`.
      *Проверка:* на каждую группу — снимки без изменений + сценарии в тесте сравнения.
- [x] 6. Найденные расхождения симуляции и прошивки — исправить в Rust-симуляции (эталон — прежний шаблон), перечислить здесь.
      Итог: расхождений в логике нет. Отличия только в способе сравнения: float в прошивке 32-битный, в симуляции 64-битный
      (тест сравнивает float с допуском 1e-4); флаги (`clamp`) в модуле симуляции подставляются литералом, как в прошивке;
      в прелюдию модуля добавлен `fmodf` (без libc).
- [x] 7. Предпросмотр C++ у Rust-блока: редактор блока (только чтение, «создать на основе»), `crab-ai get_block_type`.
      *Проверка:* тест `crab-ai` (есть пример C++ у `timer_on`); вручную в редакторе.
- [x] 8. Прогон `crablogic gen` по всем `examples/` до и после — скетчи равны; `crablogic build` одного примера через `Direct`.
- [x] 9. Справка `help/10-block-editor.md`, `help/05-build.md`, `library/README.md`, новости, файл архитектуры; переводы следом.
- [x] 10. Сверка с критериями `spec.md`; не проверенное на плате отметить явно.

## Итог сверки

- Критерии выполнены: у 30 блоков нет шаблона; снимки `crab-codegen` без изменений; `crablogic gen` по всем 36 примерам даёт те же скетчи, что до правок;
  `crablogic build examples/logic_gates` собрался (Direct); тест `builtin_cpp` проходит для всех блоков и вариантов параметров (с `CRAB_ZIG`);
  справка, `library/README.md`, новости и файл архитектуры обновлены. Переводов `help/<язык>/` в репозитории нет.
- Не проверено на плате: прошивка собирается, но на ESP32 не запускалась.
- Предпросмотр C++ в редакторе блока проверен только сборкой (окно редактора вручную не открывалось).
