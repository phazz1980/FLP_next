# Подпись наборов блоков — план

## Границы
`flp-core` работает с байтами и не знает ни про DPAPI, ни про сеть: подписывает, проверяет, решает состояние доверия. Хранение закрытого ключа (DPAPI) и загрузка списка авторов — в редакторе.

## Формат
- В `.flpblocks` добавляется файл `signature.toml`: `author` (`id`), `key_id`, `algorithm = "ed25519"`, `signature` (base64).
- Что подписывается: sha256 от канонической склейки всех файлов набора кроме `signature.toml` (имена по возрастанию, затем содержимое); `pack.toml` входит в общий хеш.
- В `pack.toml` поле `author` должно совпадать с `author` в подписи, иначе набор отклоняется.
- Список авторов: `authors/<id>.toml` в репозитории каталога: `id`, `contacts`, `keys = [{ key_id, public, revoked = false, revoked_at }]`. Локальная копия лежит в `user_library`, ручные добавления отдельным файлом `trusted.toml`.
- Правило каталога: `id` набора начинается с `author/`, публиковать под этим автором может только держатель его ключа (проверяется при приёме pull request'а; позже Action).

## flp-core
Новый модуль `sign.rs`:
- `generate_keypair() -> (SecretKey, PublicKey)`, `key_id(public)`.
- `sign_pack(files, secret, author) -> signature.toml`.
- `verify_pack(files, trust) -> Trust`, где `Trust` — `Verified { author, key_id }`, `UnknownAuthor { author, key_id }`, `Unsigned`, `Invalid`, `Revoked`, `AuthorMismatch`.
- `TrustStore { authors, trusted_local }`: загрузка, `trust(author, key)`, `is_revoked`.
- `PackImport::from_files` вызывает проверку, результат хранится в `IncomingPack`; зависимость `ed25519-dalek` (и `sha2`, он уже в плане `block-registry`).

## Редактор
- Настройки: «Создать ключ», показ кода открытого ключа, имя автора. Закрытый ключ шифруется DPAPI (`CryptProtectData`) и пишется в профиль.
- Экспорт подписывает, если ключ есть.
- Окно импорта показывает состояние `Trust` и нужные кнопки: «Доверять», «Всё равно установить», запрет при `Invalid`/`Revoked`/`AuthorMismatch`.
- Дерево блоков: значок и подсказка у наборов с отозванным ключом или без подписи.
- Список авторов обновляется вместе с индексом каталога.

## Риски
- DPAPI привязывает ключ к профилю Windows, при переустановке системы ключ пропадёт. Предлагаем экспорт резервной копии ключа (зашифрованный файл с паролем) отдельной задачей позже.
- Подпись не защищает от автора, который подписал вредоносный набор; поэтому окно импорта всегда показывает состав.
- Цикл установки: проверка подписи идёт до записи любых файлов в библиотеку.
