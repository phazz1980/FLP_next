# Образ состояния ПЛК и проект во flash

**Цель.** Отладка читает состояние платы как один упакованный образ (снимок за скан-цикл) вместо списка 4-байтных значений; в прошивке лежит сжатый проект, который можно выгрузить обратно в редактор. Образ одинаково читается по USB и по сети (web/Wi-Fi).

**Сценарии.**
1. Пользователь включает отладку → плата раз в 100 мс шлёт образ; редактор по карте смещений, полученной при сборке, показывает значения на схеме. Видно, что значения взяты из одного скан-цикла.
2. Пользователь форсирует вход или выход → значение держится, пока форсировка включена, и его видят все блоки ниже. Снял форсировку — схема работает как раньше.
3. Пользователь подключает плату, прошитую на другом компьютере → «Открыть проект с платы» → редактор получает `.crab` и открывает его.
4. Тот же образ запрашивается по web-каналу и разбирается той же картой смещений.

**Критерии готовности.**
- Скан-цикл в прошивке: снимок входов → выполнение логики → выгрузка выходов; образ копируется между сканами, а не посреди цикла.
- Наблюдаемые переменные лежат в одной упакованной структуре без выравнивания; порядок — от крупных типов к мелким (детерминированный). Размер образа не больше суммы размеров типов, `bool` занимает 1 байт.
- Редактор получает карту смещений (имя → смещение, тип) от генератора вместе с отпечатком; прошивка без совпадения отпечатка значения не показывает (как сейчас).
- Форсировка работает через маску (флаг + значение на переменную), применяется после блока-источника, переживает следующий скан; снятие флага возвращает нормальную работу.
- Запись уставки «один раз» продолжает работать.
- Сжатый `.crab` встраивается в отладочную и в рабочую прошивку (можно отключить в `project.toml`); команда протокола «выгрузить проект» отдаёт его кадрами с CRC; редактор собирает и открывает файл, проверяет отпечаток.
- С паролем встроенный архив не читается без него (проверяется тестом: выгрузка без пароля не даёт TOML); с неверным паролем — понятная ошибка.
- Протокол несёт версию; v1 редактор распознаёт и сообщает «обновите прошивку».
- Тесты: снимок сгенерированного кода с упакованной структурой, разбор образа по карте смещений, цикл «сборка → выгрузка проекта → тот же отпечаток» (без железа); на железе — отдельная проверка.
- Справка (`help/*.md`) и раздел «Онлайн-отладка» в архитектуре обновлены.

**Вне задачи.** Интерпретатор логики (стековая машина вроде MC7) — загрузка логики без перепрошивки идёт через WASM-блоки; Wi-Fi-транспорт отладки целиком (здесь только формат образа, пригодный для него); внутренние переменные блоков (отсчёт таймера) — отдельной задачей.

**Ответы пользователя (01.11.2026).**
1. Проект встраивается и в рабочую прошивку.
2. Образ шлётся целиком, если это не грузит МК; нагрузку измеряем (окно «Диагностика», `STATS`), при заметной — режим «только изменения» отдельной задачей.
3. Порядок внутри одного размера — по порядку выполнения.
4. Защита нужна: необязательный пароль проекта в `project.toml`; встроенный архив шифруется ключом из пароля, прошивка отдаёт шифротекст и пароль не знает; редактор расшифровывает. Без пароля архив не шифруется.
