# Переименование в CrabLogic

## Цель
Убрать сочетание «FLP» из программы и репозитория: проект называется CrabLogic.

## Решения пользователя
- `libs/` (сторонние FLProg_Network, Flprog_Utilites) не трогаем.
- Формат проекта — `.crab`; старые `.flpn` читаются (сохраняются уже как `.crab`).
- Переменные окружения `FLP_*` → `CRAB_*`; примеры переименовать.
- Репозиторий на GitHub переименовывает пользователь; мы готовим ссылки.
  Файлы релиза (`FLP_next-*`) переименовываются/перезаливаются только после подтверждения.
- Папку `D:\FLP_next` пользователь переименовывает сам в конце.
- Прошивка и WASM-блоки: имена `flp_*` меняются на `crab_*`; импорт-модуль WASM `"flp"`
  хост принимает и под старым именем (уже собранные блоки продолжают работать).

## Критерии готовности
- `git ls-files | grep -i flp` вне `libs/` — пусто; `git grep -i flp` вне `libs/` — только сознательные места совместимости (чтение `.flpn`, алиас модуля `"flp"`).
- `cargo fmt`, `cargo clippy --all-targets`, `cargo test` проходят.
- Пример `.flpn` открывается и сохраняется как `.crab`.

## Вне задачи
Переименование репозитория и папки; сторонние библиотеки; перезалив релиза без подтверждения.
