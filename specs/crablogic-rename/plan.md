# План
Крейты `flp-x` → `crab-x`, пути `flp_x` → `crab_x`, CLI `flp` → `crab`, кэш `.flp/` → `.crab/`,
константы/окружение `FLP_*` → `CRAB_*`, C++-идентификаторы `flp_*` → `crab_*`, `FLP_next` → `CrabLogic`.
Файлы — `git mv` (папки крейтов, снимки codegen, `docs/demo/flp_demo*`, пример `.flpn`).
Текст — скриптовая замена по всему репозиторию кроме `libs/`, `target/`, `dist/`, `Cargo.lock` (пересоздаётся).
Совместимость: загрузка `.flpn`; WASM-хост принимает модуль `"flp"`. Риск: скомпилированные `block.wasm`
и `docs/demo/*.wasm` содержат старое имя — пересобрать, где есть инструмент.
