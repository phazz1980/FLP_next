# Импорт и экспорт блоков (.flpblock)

## Цель
Передавать пользовательский блок другому человеку или на другой компьютер **одним файлом**
и сразу собирать с ним прошивку, без ручного копирования папок и установки библиотек.

## Решения (ответы пользователя)
- Один блок = один файл `<тип>.flpblock` — ZIP с теми же файлами, что в папке блока
  (`block.toml`, шаблоны, `docs.md`), плюс:
  - `lib/<Имя>/…` — исходники Arduino-библиотек, которые использует блок (папка = одна библиотека);
  - `example.flpn` — пример использования (маленький проект с этим блоком).
- Библиотека блока подхватывается сборкой (CLI и редактор) автоматически, как только блок
  стоит в `user_library/`: отдельной установки нет.
- Импорт: из файла в библиотеку; перетаскиванием файла в окно; из проекта `.flpn`
  (пользовательские блоки, упакованные в проекте).
- Экспорт: действие у блока пользовательской библиотеки → файл.
- Редактор блока: «Прикрепить библиотеку» (папка) и «Прикрепить пример» (из открытого
  проекта или файла `.flpn`), с возможностью убрать.
- Конфликт типа: спросить «заменить / оставить» с показом ревизий; встроенные блоки заменять нельзя.

## Критерии готовности
1. Экспорт → импорт на «чистой» библиотеке даёт тот же блок (файлы совпадают), с библиотекой и примером.
2. `flp build` проекта с импортированным блоком видит его `lib/` без настроек.
3. Встроенный тип и небезопасные пути в архиве (`..`, `:`) отклоняются.
4. Конфликт без подтверждения ничего не перезаписывает.
5. Пример открывается из карточки блока.

## Вне задачи
Онлайн-каталог блоков, подписи и проверка доверия к чужим блокам, версионирование библиотек.
