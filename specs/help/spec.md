# Справка программы

## Цель
Чтобы пользователь мог разобраться в редакторе, не выходя из него и не читая код: с чего начать, как устроены плата, блоки, сборка и отладка, что значит ошибка.

## Решения
- Справка — окно внутри редактора: слева дерево разделов, справа текст, сверху поиск.
- Тексты — Markdown-файлы на русском в `help/`, встраиваются в программу при сборке.
- Без скриншотов: только текст, таблицы и примеры кода.
- Справочник по блокам собирается автоматически из `docs.md` блоков библиотеки (встроенных и пользовательских).
- F1 на выбранном блоке открывает его справку. Ссылка из ошибки проверки на раздел справки — позже, когда у ошибок появятся коды.
- Первый черновик пишет ИИ по коду и спекам, автор правит.

## Сценарии
1. «Справка → Содержание» (и F1 вне блока) открывает окно на разделе «Быстрый старт».
2. Дерево разделов; клик открывает раздел; ссылки между разделами работают внутри окна, внешние открываются в браузере.
3. Поиск по заголовкам и тексту всех разделов, результаты со строкой-контекстом.
4. «Справочник блоков»: группы как в дереве библиотеки, у каждого блока описание из его `docs.md`; блок без `docs.md` показывается с портами и параметрами из `block.toml`.
5. F1 с выбранным блоком на листе открывает его страницу в справочнике.
6. Отложено: ссылка «Что это?» у ошибки проверки; пока «Справка → Частые ошибки» открывает таблицу по тексту сообщений.
7. Пользовательский блок или набор сразу появляется в справочнике после перечитывания библиотеки.

## Разделы
1. Быстрый старт: проект, плата, первая схема, сборка, заливка.
2. Редактор: платы-листы, дерево, теги, привязки, горячие клавиши.
3. Схема: блоки, связи, типы портов, проверка, порядок выполнения.
4. Библиотека блоков: свои блоки, наборы, импорт и экспорт.
5. Сборка и прошивка: arduino-cli, ядра, заливка, ошибки сборки.
6. Онлайн-отладка: подключение по USB, живые значения, уставки, форсировка.
7. ИИ-помощник и MCP: чат, команды, подключение внешнего клиента.
8. Частые ошибки: сообщения проверки схемы и сборки, что делать.
9. Что нового: по версиям.
10. Справочник блоков (автоматический).

## Критерии готовности
- Все разделы 1–9 написаны, ссылки между ними не битые (проверяет тест).
- Тест: каждая ссылка `help:` указывает на существующий раздел.
- Поиск находит слово из любого раздела и из `docs.md` блока.
- Справочник блоков содержит все блоки библиотеки; блок без `docs.md` не ломает его.
- Окно работает на тёмной и светлой теме и не тормозит на справочнике из всех блоков.
- Сведения в справке не расходятся с программой: при выпуске версии раздел «Что нового» обновляется (пункт в процессе выпуска).

## Вне задачи
Скриншоты и видео, версия справки на английском, экспорт в HTML/PDF, справка в формате `.chm`, онлайн-сайт, пошаговые обучающие сценарии внутри редактора.

## Открытое
- Рендерер Markdown не умеет картинки; если они понадобятся, расширять отдельно.
- Как держать раздел «Что нового» в соответствии с процессом выпуска (`release-process`): сейчас список версий лежит в релизах GitHub.
