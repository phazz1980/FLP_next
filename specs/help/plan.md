# Справка программы — план

## Файлы
- `help/*.md` в корне репозитория: по файлу на раздел (`01-quickstart.md`, `02-editor.md`, …). Первая строка — `# Заголовок`; порядок по имени файла. Подразделы — заголовки второго уровня, якоря берутся из них.
- Встраивание: `build.rs` у `flp-editor` или `include_dir`-подобный макрос; без новой зависимости достаточно списка `include_str!` в одном модуле `help_pages.rs`, который проверяется тестом на полноту (все `help/*.md` в списке).

## Код (в `flp-editor`, ядро не затрагиваем)
- `help.rs`:
  - `Page { id, title, text }` и `pages()` из встроенных файлов.
  - `search(query, pages, block_docs)` — поиск по заголовкам и тексту без учёта регистра, возвращает страницу, якорь и строку-контекст.
  - `HelpWindow` — состояние окна: открытая страница, прокрутка, строка поиска, история «назад».
  - Справочник блоков: из `Library` собираются страницы групп; текст блока — его `docs.md`, иначе таблица портов и параметров из `block.toml`.
- `markdown.rs`: ссылки со схемой `help:<страница>#<якорь>` отдаются наружу как событие, а не открываются в браузере; внешние `https://` и `mailto:` — как сейчас. Якоря: рендерер запоминает позицию заголовков для прокрутки.
- `app.rs`: пункт «Справка → Содержание», горячая клавиша F1 (с выбранным блоком — страница блока). Окно не модальное, не блокирует редактор.
- Коды ошибок: у `Diagnostic` только текст, поэтому ссылка «Что это?» и таблица «вид → раздел» отложены до появления кода ошибки в ядре; пока «Частые ошибки» — таблица по тексту сообщений.

## Тесты
- Разбор ссылок `help:`; все ссылки в `help/*.md` ведут на существующие страницы и якоря.
- Поиск: находит слово, учитывает регистр кириллицы, ничего не находит на пустой запрос.
- Справочник блоков: блок без `docs.md` даёт страницу из `block.toml`.

## Риски
- Справка устаревает, когда меняется программа. Смягчаем тестами на ссылки и коды ошибок и пунктом в процессе выпуска; сами тексты держим короткими, без пошаговых описаний интерфейса, которые быстро меняются.
- Объём: десять разделов, пишем от общего к частному, раздел можно выпускать неполным, но без битых ссылок.

## Архитектура
Добавить короткий раздел про справку (где лежит, как собирается) в файл архитектуры, когда готовы задачи 1–7.
