# Веб-демо редактора (сборка и симуляция в браузере)

## Цель
Дать открыть по ссылке на GitHub Pages (`/demo/`) облегчённую версию редактора и без установки
увидеть, как работает CrabLogic: открыть пример, посмотреть схему, нажать «Сборка» и «Симуляция».
Только демонстрация: не замена настольной программы.

## Сценарии
1. Открываю страницу, выбираю пример из списка (насос, мигалка, логика, термостат…) — схема рисуется на листе.
2. Нажимаю «Сборка»: проверка схемы (ошибки по-русски) и показ сгенерированного Arduino C++ скетча.
3. Нажимаю «Симуляция»: время идёт (пауза, шаг, 1×/10×), щёлкаю по входам — выходы и связи меняются.
4. Загружаю свой `.flpn` и скачиваю собранный скетч `.ino`.

## Критерии готовности
- Страница работает в Chrome, Edge и Firefox без сервера (чистая статика на Pages).
- Проверка, генерация и симуляция — тот же код, что в программе (`flp-core`, `flp-codegen`, `flp-sim`), собранный в WASM; вывод скетча для примера совпадает с настольным.
- Примеры вшиты в страницу; библиотека блоков — вшита.
- Размер страницы вместе с WASM — разумный (цель ≤ 10 МБ), на лендинге есть ссылка на демо.

## Вне задачи
Компиляция в бинарник, заливка, USB-отладка, ИИ-чат, редактирование схемы (первая версия — только просмотр),
блоки с железом и сетью (их выходы задаются руками, как в настольной симуляции).

## Решено
- Только просмотр: примеры и загрузка `.flpn`, править схему нельзя.
- Интерфейс — egui (eframe) в WASM, тот же вид листа, что в программе.
- Примеры: pump, blink, logic_gates, thermostat, start_stop, toggle.
