# Коды ошибок проверки схемы

## Цель
У каждой ошибки и предупреждения проверки схемы есть устойчивый вид (код). По нему редактор показывает ссылку «Что это?» на описание в справке, а справка гарантированно описывает все виды.

## Сценарии
1. В окне/панели результатов проверки (F7) у сообщения есть ссылка «Что это?»; клик открывает «Частые ошибки» на строке этого вида.
2. Новый вид ошибки нельзя добавить в ядро без описания в справке: тест падает.
3. ИИ и MCP получают код вместе с сообщением и могут ссылаться на него.

## Критерии готовности
- У `Diagnostic` есть поле вида; все сообщения `check.rs` его имеют.
- Тест: каждый вид из ядра есть в таблице «Частые ошибки» (по якорю или идентификатору в тексте).
- Тест: каждая ссылка «Что это?» ведёт на существующий раздел.
- Текст сообщений для пользователя не меняется.

## Вне задачи
Коды ошибок сборки `arduino-cli` (у них своя нумерация); перевод сообщений на другие языки.
