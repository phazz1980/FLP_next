# Наборы блоков (block packs)

## Цель
Держать несколько своих блоков вместе под одной версией и переносить их одним файлом.

## Сценарии
1. «Новый набор» в окне пользовательской библиотеки: имя, описание → папка набора.
2. При создании блока выбираю набор (или «без набора»); готовый блок можно перенести в другой набор.
3. «Экспорт набора» → один файл `<имя>.flpblocks` со всеми блоками набора, их Arduino-библиотеками и примерами.
4. «Импорт» принимает только `.flpblocks`; двойной щелчок и перетаскивание тоже. Формат `.flpblock` убираем.
5. Правка любого блока набора поднимает версию набора на 1. У блоков внутри набора своей версии нет.
6. Импорт набора, который уже есть: версия выше — заменяется целиком; та же или ниже — спрашивает.

7. Автор: в наборе указываются `author`, `contacts` (список: почта, ссылки, соцсети, например `me@mail.ru`, `t.me/name`, `https://vk.com/name`) и `license`. Имя автора по умолчанию задаётся в настройках редактора и подставляется в новые наборы. Редактор показывает автора и контакты в дереве блоков и окне импорта; контакт — кликабельная ссылка (почта → `mailto:`, без схемы → `https://`).
8. Правка набора с другим автором: редактор спрашивает, добавить ли себя в `authors`.

## Критерии готовности
- Набор = папка в `user_library/` с `pack.toml` (`name`, `version`, `description`); блоки лежат в ней, в дереве блоков набор — своя группа.
- Экспорт → импорт на чистой библиотеке даёт те же блоки, ту же версию набора.
- Импорт более новой версии удаляет из набора блоки, которых в новой версии нет.
- Блок со встроенным типом по-прежнему не заменяется; конфликт типа с блоком другого набора — вопрос пользователю.
- Обратной совместимости нет: `.flpblock`, поле `version` в `block.toml` и блоки вне набора удаляются из кода; каждый блок живёт в наборе (по умолчанию «Мои блоки»), существующие блоки в `user_library/` переносятся туда вручную один раз.
- Тесты в `flp-core`: roundtrip набора, обновление, удаление лишних блоков, конфликты.

- `pack.toml` содержит `author`/`authors`, `contacts`, `license`; контакты открываются кликом.

## Вне задачи
Скачивание наборов из сети, зависимости между наборами, подпапки внутри набора, криптографическая подпись наборов (автор — только пометка, не защита от подделки). Пользователей будет несколько, поэтому подпись и доверенные авторы — следующая спека `specs/block-signing/`.
