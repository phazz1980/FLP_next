# План: встроенные блоки на Rust, шаг 3

- `crates/flp-blocks/src/hardware.rs` — 13 функций `emit` (по одной на блок); `lib.rs` — записи в таблице `BLOCKS`; трейт `BuiltinBlock::behavior` возвращает `Option` (у блоков с железом симуляции нет).
- `CppCtx.expander: Option<(String, String)>` — слова расширителя пинов (чтение, запись); заполняет `flp-codegen` из `expander::state_names`.
- Булев параметр попадает в `CppCtx::param` как `true`/`false` (раньше — текст шаблонизатора).
- Устройства пользовательских плат (`flp-core::devices`) копируют родительский блок: если у родителя нет шаблона, копия берёт код встроенного Rust-блока через `BlockInfo.code_of` (в `block.toml` не пишется).
- Порядок источников кода прошивки: шаблон в папке > Rust-блок > `block.wasm`.
- Риск: тонкости пробелов и переводов строк. Закрыт побайтным сравнением со старым выводом.
- Строки `decoder`/`encoder` по-прежнему склеены в одну строку, как у шаблонов (побайтное совпадение).
