# Веб-ввод текста и страница настройки сети

**Цель.** Вводить сетевые параметры (SSID, пароль Wi-Fi, брокер, логин, Client ID, пароль OTA) с веб-страницы платы и сразу видеть, применились ли они.

**Сценарий.** Плата поднимает свою точку доступа, пользователь открывает `/ui`, вводит значения; плата переподключается, индикаторы показывают Wi-Fi, брокер и адрес.

**Готово, когда:**
- [x] блок `web_text_input` даёт строковый выход; поле может быть скрытым (пароль) и не возвращается на страницу;
- [x] пример `examples/net_setup` проходит `flp check`, снимок скетча в тестах;
- [x] справка и архитектура обновлены;
- [ ] проверено на железе (скетч целиком не собран: библиотека `RT_HW_BASE` не собирается с текущим ядром ESP32 — то же и у `examples/web_ui`).

**Вне задачи.** Сохранение введённого во флеш (после перезагрузки поля пусты; для этого есть `web_net`); порт брокера (число — `web_input`).
