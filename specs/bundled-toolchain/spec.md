# Инструменты сборки рядом с программой

## Цель
Программа собирает прошивки «из коробки», не требуя от пользователя ставить `arduino-cli` и ядро ESP32 вручную,
и не засоряет профиль пользователя. Версии фиксированы, чтобы сборка была воспроизводимой.

## Сценарии
1. В архиве `arduino-cli.exe` лежит в корне программы; ядро ESP32 — в папке `esp32core` рядом (если положено при сборке архива).
2. `arduino-cli` ищется: `CRAB_ARDUINO_CLI` → корень программы → `PATH` → `Program Files\Arduino CLI`.
3. Ядро ищется: папка `esp32core` → системная папка данных arduino-cli (`%LOCALAPPDATA%\Arduino15`).
4. Нет `arduino-cli` — при запуске окно с предложением скачать фиксированную версию (1.5.1) в корень программы
   и сразу докачать ядро ESP32 (3.3.12) в `esp32core`.
5. Есть `arduino-cli`, нет ядра — первая сборка ставит фиксированную версию ядра в `esp32core`.

## Критерии готовности
- `ArduinoCli::locate()` предпочитает копию в корне программы; тест порядка поиска.
- Если `esp32core` содержит ядро, команды идут с `ARDUINO_DIRECTORIES_DATA=<esp32core>`; иначе — с системной папкой.
- Скачанный архив `arduino-cli` проверяется по SHA-256 из кода.
- `build-dist.ps1` кладёт `arduino-cli.exe` и, если есть, `esp32core` (ключ `-WithCore`) в архив.
- Справка и README дистрибутива обновлены.

## Вне задачи
Библиотеки Arduino (остаются в пользовательской папке), Rust-тулчейн, Linux/macOS-загрузка, обновление фиксированных версий.
