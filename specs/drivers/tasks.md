# Нативная часть блока и скриптовые блоки — задачи

Порядок важен: каждая задача проверяется до следующей.

- [x] 1. Формат нативной части: разбор `native.cpp` (`// crab:native`, `// crab:sim`, `CRAB_INIT`, `CRAB_STEP`) в
  `crab-core::native`, `LibraryBlock::native_part()`, проверка при загрузке блока (битый файл — блок не попадает в библиотеку,
  `Error::InvalidNative`), проверка типов портов и `crab:sim` по интерфейсу. Полей `native`/`logic` в `block.toml` нет: часть есть,
  если лежит файл. Проверено: 8 тестов (разбор, ошибки по-русски с номерами строк, типы, загрузка из папки).
- [ ] 2. Мастер из нативных частей: `MasterFeatures`, `native.cpp` в скетче, экземпляр блока = свой `State`, отпечаток.
  Проверка: сборка мастера с двумя блоками и без, два экземпляра одного блока независимы, разные отпечатки.
- [ ] 3. Заглушка нативной части в симуляции по `// crab:sim`. Проверка: блок с `native.cpp` идёт в `crab-sim` и в схеме.
- [ ] 4. Проверка схемы: нативной части блока нет в мастере на плате — сообщение по-русски, что нужна сборка мастера; редактор
  показывает, что доступно без перепрошивки.
- [ ] 5. `crab-script`: лексер и разбор подмножества. Проверка: тесты на примерах, ошибки с номером строки.
- [ ] 6. `crab-script`: проверка типов и вывод в WASM. Проверка: сверка с `crab-sim`, как у встроенных блоков.
- [ ] 7. Блок с `logic.crs` в схеме: сборка листа, права `allow`. Проверка: пример в `examples/`, снимок модуля.
- [ ] 8. Редактор блока: вкладка «Нативная часть» (C++-редактор, заголовки, пробная генерация), «Собрать мастер для проверки».
  Проверка: I²C-датчик на заглушке собирается в `arduino-cli`.
- [ ] 9. Шаблоны «Создать по шаблону»: GPIO/1-Wire, I²C с таблицей регистров, SPI, UART/Modbus, библиотека Arduino. Проверка:
  сборка по одному примеру на каждый.
- [ ] 10. Вызовы нативных функций из скрипта (`CRAB_EXPORT`, `uses`) — второй шаг; заглушки в симуляции.
- [ ] 11. Справка (`help/`, `10-block-editor.md`), `docs.md`, раздел в `Архитектура и план.md`; перевод справки следом.
- [ ] 12. После формы: ИИ-режим (создать блок с нативной частью и логикой в общем наборе ИИ).
- [ ] 13. Сверка с критериями спеки; не проверено на железе — записать.
