# Каталог наборов блоков — задачи

Предусловие: закончена и закоммичена работа по `specs/block-packs/`.

- [ ] 1. `PackInfo`: поля `id`, `format`, `requires`; чтение/запись `pack.toml`. Проверка: тест roundtrip в `flp-core`.
- [ ] 2. `from_files` отклоняет неизвестный `format`. Проверка: тест с набором `format = 99`.
- [ ] 3. `registry.rs`: `Index::parse`, битый индекс даёт ошибку. Проверка: тесты на корректный, пустой и неполный индекс.
- [ ] 4. `verify_sha256`. Проверка: тест на верный и подменённый файл.
- [ ] 5. `updates`: сравнение версий. Проверка: тест (новее, равно, старее, не установлен).
- [ ] 6. `resolve`: зависимости, порядок, цикл, нет набора, версия ниже. Проверка: по тесту на каждый случай.
- [ ] 7. `dependents` для предупреждения при удалении. Проверка: тест.
- [ ] 8. Редактор: настройка `registry_url`, фоновая загрузка индекса, обработка отсутствия сети. Проверка: вручную, с выключенной сетью установленное работает.
- [ ] 9. Окно «Каталог»: список, поиск, карточка (автор, контакты, лицензия, блоки, библиотеки, зависимости). Проверка: вручную на тестовом `index.toml` (файловый URL).
- [ ] 10. «Установить» и «Обновить» с зависимостями: сначала скачать и проверить всё, потом ставить. Проверка: вручную, с одним файлом с неверным хешем не ставится ничего.
- [ ] 11. Предупреждение при удалении набора с зависимыми. Проверка: вручную.
- [ ] 12. Создать организацию и репозиторий `registry`, вписать адрес в константу. Делает владелец.
- [ ] 13. Раздел про каталог в файле архитектуры.
- [ ] 14. Сверка с критериями спеки; не проверенное (реальная сеть, железо) записать сюда.
