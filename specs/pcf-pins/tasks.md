# Задачи: выводы на расширителях PCF

- [x] 1. `expander.rs`: `Expander`, `Chip` (число выводов, адреса), чтение/запись в `logic.toml`, `Block.expander`, `BlockDef.expander`. Проверка: тесты roundtrip, старый проект без `[[expander]]` читается и пишется без изменений.
- [x] 2. `check.rs`: вывод занят, вне диапазона, нет расширителя, повтор адреса; `pin_uses` пропускает блоки на расширителе. Проверка: тесты на каждый случай, `flp check` по-русски; коды в `specs/error-codes`.
- [x] 3. `edit.rs`: команды создания, правки, удаления расширителя и назначения блоку. Проверка: тесты команд, удаление с занятыми выводами.
- [x] 4. Генерация: состояние расширителя, чтение в начале прохода, запись в конце, ветка `{% if expander %}` в `digital_in`/`digital_out`. Проверка: снимок нового примера, снимки старых примеров не меняются.
- [x] 5. Пример `examples/pcf_pins/` (PCF8574 и PCF8575, входы и выходы вперемешку). Проверка: `flp check`, `flp gen`, `flp build`.
- [x] 6. Редактор: источник вывода в `pin_combo`, окно «Добавить расширитель...», подписи в дереве, раздел «Расширители». Проверка: тест логики окна без графики + ручной запуск (окна проверены только сборкой и юнит-тестом, не глазами).
- [x] 7. `flp-ai`/MCP: команды расширителей. Проверка: тест инструментов.
- [x] 8. Документы: справка, `library/README.md`, файл архитектуры, новости.
- [x] 9. `cargo fmt`, `clippy --workspace --all-targets`, `cargo test --workspace`; сверка с критериями спеки.
