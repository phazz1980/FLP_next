# Виджеты редактора → веб-конструктор

**Цель.** Виджет, добавленный (или удалённый) в редакторе схемы, сразу виден в веб-конструкторе — в правой панели «Не размещённые»; оттуда его ставят на страницу.

**Сценарий.** Пользователь кладёт `web_switch` на лист → в конструкторе (открытом) через ~2 с в правой панели появляется «Не размещённые (1)». Перетаскивает виджет на сетку или щёлкает по нему — виджет встаёт на текущую страницу. Удалил виджет в редакторе — он пропал и из конструктора.

**Критерии.**
- Новый виджет без явной строки имеет `row = 0` и в сетку не попадает, а лежит в списке.
- В прошивке такой виджет не теряется: страница ставит его под размещёнными.
- Пока конструктор запущен, правка веб-виджетов в редакторе сохраняется в файл сразу (не ждёт автосохранения).
- Размещение (перетаскивание или щелчок) пишет `page`, `col`, `row`.

**Вне задачи.** Живой канал без файла; размещение из редактора.

**Как устроено.** Признак «не размещён» — `row = 0` (по умолчанию в `block.toml` виджетов). Редактор сравнивает отпечаток `web_*` блоков и при изменении сохраняет проект, если конструктор запущен.
