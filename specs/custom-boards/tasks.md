# Задачи: пользовательские платы

- [ ] 1. `PinInfo`: подпись и владеющее предупреждение, без `Copy`; `BoardLayout` над `Chip`. Проверка: тесты `pins.rs`, `uart.rs`, `check.rs` проходят без изменения ожиданий.
- [ ] 2. `boards.rs`: `BoardDef`, чтение/запись `board.toml`, проверка файла, `Boards::load` (встроенные + пользовательские). Проверка: roundtrip, повтор GPIO, GPIO вне чипа, битый файл не мешает остальным.
- [ ] 3. `BoardLayout::of_board` ищет пользовательскую плату по `board.model` и `fqbn`; `check.rs` и `flp-ai` берут пины оттуда. Проверка: тест — пин вне таблицы → ошибка, занятый → предупреждение.
- [ ] 4. `library.rs`: пропуск папки `boards`, поле `board` у блока. Проверка: тест — папка `boards` не раздел.
- [ ] 5a. Встроенные блоки `library/pcf8574_out` и `library/pcf8574_in` (адрес, пины шины, полярность, `once`-инициализация `Wire`), `docs.md`, пример в `examples/`. Проверка: снимки генерации (в т.ч. два блока с разными адресами — один `Wire.begin`), `flp check`/`flp build` примера.
- [ ] 5b. `devices.rs`: `[[device]]` платы → настроенная копия встроенного блока (адрес, шина, полярность, имена каналов зафиксированы). Проверка: снимок для реле и входов A6, тест на «блок чужой платы».
- [ ] 6. `check.rs`: блок чужой платы → ошибка по-русски. Проверка: тест.
- [ ] 7. Упаковка в `.flpn` и распаковка недостающей платы. Проверка: тест «чистая библиотека + проект с платой».
- [ ] 8. `.flpboard`: экспорт/импорт, проверка путей, конфликт id. Проверка: тесты как у `blockfile.rs`.
- [ ] 9. Редактор: список плат из `Boards` в `boardcfg.rs`, подписи пинов в списках. Проверка: ручной запуск + тест данных диалога.
- [ ] 10. Редактор: окно `boardedit.rs` — вкладки «Плата», «Выводы», «Периферия» (добавить расширитель PCF: адрес, пины шины, полярность, имена каналов), «Описание»; «Создать на основе», «Удалить». Проверка: headless-тест сохранения в папку + ручной запуск.
- [ ] 11. Описание: просмотр в окне платы, добавление изображений в `images/`, перетаскивание. Проверка: тест копирования файла и ссылки, картинка видна в окне.
- [ ] 12. Импорт/экспорт `.flpboard` в редакторе (меню, перетаскивание), регистрация расширения в `assoc.rs`.
- [ ] 13. Пример `examples/kc868_a6_relays/` (кнопка → реле) и плата `examples/boards/kincony_kc868_a6/` с описанием и пометками «не проверено». Проверка: `flp check`, `flp gen`, `flp build` для `esp32:esp32:esp32`.
- [ ] 14. Документы: `help/` (страница «Свои платы», новости), файл архитектуры, `library/README.md` при необходимости.
- [ ] 15. `cargo fmt`, `clippy --all-targets`, `cargo test`; сверка с критериями спеки; в отчёте — что не проверено на железе.
