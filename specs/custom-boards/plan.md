# План: пользовательские платы

## Формат `user_library/boards/<id>/`
```
board.toml      описание платы
docs.md         текст; картинки как ![схема](images/scheme.png)
images/         фото и схемы (png/jpg)
blocks/<тип>/   свои блоки платы (необязательно, формат обычного блока)
```
`board.toml`:
```toml
[board]
id = "kincony_kc868_a6"       # = имя папки, пишется в project.toml как board.model
name = "Kincony KC868-A6"
chip = "esp32"                # esp32 | esp32c3 | esp32s3 — правила АЦП/UART берутся от чипа
fqbn = "esp32:esp32:esp32"
version = 1
[board.options]               # необязательно, меню платы arduino-cli по умолчанию

[[pin]]                       # выведенные GPIO; флаги (АЦП, только вход, flash) — от чипа
gpio = 36
name = "A1"                   # что подключено — подпись в списках пинов
note = "аналоговый вход 0–5 В"
busy = "…"                    # необязательно: пин занят на плате, причина (предупреждение)

[[device]]                    # встроенная периферия: настроенный экземпляр встроенного блока
kind = "pcf8574_out"          # тип встроенного блока: pcf8574_out | pcf8574_in (позже pcf8575_*)
address = 0x24
sda = 4
scl = 15
inverted = true
channels = ["K1", "K2", "K3", "K4", "K5", "K6"]
```

## Затронутые крейты и файлы
- **flp-core**
  - новый `boards.rs`: `BoardDef` (serde), `Boards` (встроенные + `user_library/boards/`, ошибки на плату),
    `BoardLayout { chip, name, pins }` — единая таблица пинов вместо `Chip::pins()` в проверке/редакторе;
    сохранение, проверка файла (повтор GPIO, GPIO нет у чипа, пустой id);
  - `pins.rs`: `PinInfo` получает подпись (`label`) и владеющую строку предупреждения (теряет `Copy` —
    правки в местах использования); `Chip` остаётся семейством; ESP32-C3 Super Mini остаётся встроенной
    (`BOARD_MODELS`), `BoardLayout::of_board(&BoardConfig, &Boards)` сначала ищет пользовательскую плату;
  - `library/pcf8574_out/`, `library/pcf8574_in/` (+ `docs.md`, пример в `examples/`): **встроенные блоки**
    с параметрами `address`, `sda`, `scl`, `inverted`; шаблон на голом `Wire` без сторонних библиотек,
    `Wire.begin` в секции `once`; один блок на микросхему, состояние выходов — байт в глобальной переменной;
  - `devices.rs`: `[[device]]` платы → копия встроенного блока с зафиксированными параметрами и подписями
    каналов (`inline_templates` от родителя, без файлов на диске); тип — `<board>_<имя>`, `board` у блока;
    так окно платы и обычный проект используют один и тот же шаблон;
  - `library.rs`: поле `[block] board` у блока; `read_user_tree` пропускает верхнюю папку `boards`;
    блоки платы загружаются с пометкой платы; `check.rs`: блок чужой платы → ошибка, пины — по `BoardLayout`;
  - `packed.rs`: `boards/<id>/` едет в `.flpn` (`PACKED_BOARDS`) и разворачивается, если платы нет (как блоки);
  - `boardfile.rs`: экспорт/импорт `.flpboard` (ZIP, проверка путей) по образцу `blockfile.rs`.
- **flp-editor**: `boardcfg.rs` — список плат из `Boards`, пункты «Новая плата… / Редактировать / Создать на основе /
  Удалить / Описание»; новый `boardedit.rs` — окно с вкладками; описание — просмотр через `markdown.rs`,
  правка текстовым полем, «Добавить изображение…» копирует файл в `images/` и вставляет ссылку (перетаскивание
  файла тоже); `dialogs.rs`/список пинов — подписи; импорт/экспорт `.flpboard`; горячая подгрузка уже есть
  (`newest_mtime_deep` по `user_library`).
- **flp-ai / flp-mcp**: `get_schema` отдаёт имена пинов платы; создание платы ИИ — вне задачи.
- **flp-cli**: `Boards` грузятся вместе с библиотекой (`check/gen/build` без новых команд).
- Документы: `help/` — страница «Свои платы», новости, раздел «Формат проекта»/«Платы» в файле архитектуры.

## Пример KC868-A6 (по каталогу ESPHome и форуму Kincony, на железе не проверено)
ESP32; I2C SDA=GPIO4, SCL=GPIO15 (strapping); PCF8574 0x24 — реле K1–K6 (P0–P5, в ESPHome `inverted`),
0x22 — входы X1–X6 (P0–P5, `inverted`); АЦП A1–A4 = GPIO36/39/34/35; ЦАП DA1/DA2 = GPIO26/25;
1-Wire IO-1/IO-2 = GPIO32/33; RS485 RX=14, TX=27; RS232 — источники расходятся (RX17/TX16 против tx17/rx16);
SPI CLK18/MOSI23/MISO19/CS5; LoRa RST21/DIO0 2. Ethernet в этой версии платы нет (со слов пользователя) —
в описание и таблицу выводов не включаем. Форум Kincony называет SDA 26/SCL 23 — противоречит ESPHome,
сверить со схемой. Полярность реле — параметр устройства, чтобы поменять без правки шаблона.

## Риски
- `PinInfo: Copy` используется в ~десятке мест (проверка, диалоги, `uart.rs`) — рефакторинг делаем отдельной
  задачей до новых функций, тесты `pins.rs`/`uart.rs` должны пройти без изменения ожиданий.
- Папка `boards` внутри `user_library/` не должна читаться как раздел библиотеки блоков и набор (`pack.toml`).
- Полярность реле и пины RS232/I2C A6 не подтверждены железом — пометки в описании платы и в итоговом отчёте.
- Два блока платы вызывают `Wire.begin` — только через секцию `once`, проверить снимком.
