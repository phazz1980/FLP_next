# Параметр как вход блока

## Цель
У любого блока (встроенного и пользовательского) каждый подходящий параметр можно одной галочкой
превратить во вход: значение приходит по связи и читается на каждом скане, поэтому его можно
менять на лету (уставка таймера, порог сравнения, период генератора).

## Сценарии
1. В свойствах блока рядом с параметром «Время» ставлю галочку «Вход» — у блока появляется вход
   `time`, параметр в свойствах гаснет.
2. Подаю на этот вход выход другого блока или переменную — прошивка берёт значение оттуда.
3. Не подаю ничего — работает прежнее значение параметра как константа.
4. Снимаю галочку: вход пропадает, связь на него удаляется (с записью в журнал), параметр снова
   редактируется.
5. То же для блока, который я сам создал в редакторе блоков, — без правок его шаблона.
6. В симуляции и онлайн-отладке такой вход виден и работает как обычный.

## Критерии готовности
- Галочка есть у параметров типов число (int/float), время и bool с флагом `runtime`; у pin, text
  и параметров со списком выбора её нет (их значение меняет сам код).
- Вход добавляется на конкретный блок схемы, а не на тип: другие блоки того же типа не меняются.
- Тип входа: int → int, float → float, время → int (мс), bool → bool.
- Шаблоны блоков (встроенных и пользовательских) не меняются: генератор подставляет вместо
  значения параметра выражение входа.
- Сгенерированный скетч компилируется; на каждый тип параметра есть снимок.
- `crablogic check` видит несуществующий вход, несовместимый тип, цикл без памяти через такой вход.
- Сохранение и загрузка: список параметров-входов хранится в блоке (`param_in = [...]`).
- Симуляция схемы считает такой вход (встроенные блоки и блоки с `block.wasm`).
- Справка (`03-schema.md`, `10-block-editor.md`) обновлена.

## Вне задачи
Параметры pin/text/списки; параметры, значение которых нужно на этапе генерации (размеры
массивов, инициализаторы глобальных переменных) — для них галочка недоступна, если автор блока
пометил параметр `static = true`.
