# RT_HW_STM32_SlaveBridge

Проект прошивки для STM32, выступающего как внешнее устройство с интерфейсом I2C (и в будущем SPI/UART/RS485/CAN), реализующее управление датчиками и функциями с точными таймингами.

## 📦 Цель проекта
- Унифицировать работу с тайминго-чувствительными сенсорами (DS18B20, NST1001 и др.)
- Снять нагрузку с основного микроконтроллера
- Обеспечить совместимость с RT_HW_BASE и FLProg

## ⚙️ Реализация
- STM32 работает как **I2C Slave** по адресу `0x42`
- Поддерживает команды:
  - `0x10` — Ping (вернёт версию)
  - `0x11` — Получить уникальный ID MCU
  - `0x20` — Чтение температуры с DS18B20
  - `0x30` — Чтение данных с NST1001
  - `0x40` — Прочитать счётчик импульсов

## ✅ Особенности
- Использует `RT_HW_BASE.h` для совместимости и отладки
- Лёгкий, модульный код, расширяемый под другие интерфейсы
- Работает в Arduino-стиле, можно прошивать через ST-Link

## 🔧 Используемые STM32
Для отладки используется STM32F103CB, в будущем — переход на STM32G0/F3 с поддержкой CAN

## 📡 Протокол I2C
- Master отправляет команду (1 байт), например `0x10`
- STM32 отвечает данными в `requestEvent`
