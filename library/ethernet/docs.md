# Ethernet W5500

Проводная сеть на модуле WizNet W5500 (подходят W5100 и W5200) по шине SPI.
Выводы SPI назначаются параметрами `sck`, `miso`, `mosi` и `cs`; по умолчанию для ESP32 DevKit
SCK — 18, MISO — 19, MOSI — 23, CS — 5. Выход `ready` — есть ли связь, выход `address` (параметр
«Выход IP») — IP-адрес строкой, пока связи нет, строка пустая.

Блок один на проект. У «Modbus TCP Slave» выберите `net = "ethernet"`, чтобы
он работал через этот блок.

Пример: `examples/modbus_ethernet`.

## Веб-страница

Блок всегда поднимает веб-сервер на порту 80 (отдельной настройки нет): на нём работают страницы
блока «Веб-интерфейс» (`web_ui`), в том числе страница «Система» — IP, MAC, аптайм, дата сборки
(у Wi-Fi ещё уровень сигнала). У Wi-Fi и Ethernet в одном проекте свои серверы, каждый на своём интерфейсе.

## В модуле WASM

Блок работает и в модуле (`crablogic gen-wasm`): интерфейсом W5500 владеет мастер-прошивка, модуль один раз
передаёт выводы, MAC, DHCP и адреса, а на каждом шаге читает `ready` и `address`. Выводы SPI и MAC
мастер берёт при первом запуске интерфейса: их смена требует перезагрузки платы, а DHCP и адреса
применяются на лету. Wi-Fi и Ethernet можно использовать одновременно, у каждого свой адрес; время
по кабелю берёт `ntp` с `net = "ethernet"`. Веб-страница в модуле пока не работает
(страница работает через мастер, см. «Веб-интерфейс»), параметры из переменных не поддержаны. Пример —
`examples/net_eth_wasm`. Не проверено на железе.

## Период опроса сети

Параметр «Период опроса сети, мс» (по умолчанию 5) ограничивает, как часто обслуживаются сеть, MQTT,
веб-страница: не чаще одного раза за период. Отклик запаздывает не больше чем на период.
0 — обслуживать в каждом цикле.
