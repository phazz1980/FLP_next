# Ethernet W5500

Проводная сеть на модуле WizNet W5500 (подходят W5100 и W5200) по шине SPI.
Выводы SPI назначаются параметрами `sck`, `miso`, `mosi` и `cs`; по умолчанию для ESP32 DevKit
SCK — 18, MISO — 19, MOSI — 23, CS — 5. Выход `ready` — есть ли связь, выход `address` (параметр
«Выход IP») — IP-адрес строкой, пока связи нет, строка пустая.

Блок один на проект. У «Modbus TCP Slave» выберите `net = "ethernet"`, чтобы
он работал через этот блок.

Пример: `examples/modbus_ethernet`.

## Веб-страница и обновление прошивки

Пока включён параметр «Веб-страница» (по умолчанию да), блок поднимает страницу на порту 80:
IP, MAC, аптайм, дата сборки, состояние обновления (у Wi-Fi ещё уровень сигнала).

- «Загрузка прошивки» — на странице форма выбора `.bin`; файл уходит на порт 8080 и пишется
  прямо в память (`Update`), потом устройство перезагружается. Нужен `.bin` приложения
  (Скетч → Экспорт бинарного файла), не «merged».
- «Обновление по сети» — OTA библиотеки flprogNetwork (менеджер OTA, Arduino IDE).
- «Пароль OTA» общий для обоих способов; пустой — обновлять может любой в сети.
- Wi-Fi и Ethernet в одном проекте займут одни порты 80 и 8080: у одного из блоков страницу выключите.

## В модуле WASM

Блок работает и в модуле (`flp gen-wasm`): интерфейсом W5500 владеет мастер-прошивка, модуль один раз
передаёт выводы, MAC, DHCP и адреса, а на каждом шаге читает `ready` и `address`. Выводы SPI и MAC
мастер берёт при первом запуске интерфейса: их смена требует перезагрузки платы, а DHCP и адреса
применяются на лету. Wi-Fi и Ethernet можно использовать одновременно, у каждого свой адрес; время
по кабелю берёт `ntp` с `net = "ethernet"`. Веб-страница и обновление по сети в модуле пока не работают
(параметры `web`, `web_update` игнорируются), параметры из переменных не поддержаны. Пример —
`examples/net_eth_wasm`. Не проверено на железе.

## Период опроса сети

Параметр «Период опроса сети, мс» (по умолчанию 5) ограничивает, как часто обслуживаются сеть, MQTT,
веб-страница и OTA: не чаще одного раза за период. Отклик запаздывает не больше чем на период.
0 — обслуживать в каждом цикле.
