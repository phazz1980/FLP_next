# Чтение из UART

Принимает данные из UART. UART1 и UART2 настраиваются в настройках платы
(скорость, формат, выводы); UART0 есть у ESP32-C3/S3 (у ESP32 это USB-мост).
Порт «USB»: строки приходят из вкладки
«Монитор порта» редактора, а во время отладки — из строки ввода консоли отладки
(они идут на плату кадрами `TEXT_IN` вместе с отладочным обменом, буфер — 255 байт).
Читатель у порта один: байт, взятый этим блоком, другим уже не достанется.

**Строками** (`mode = 0`, по умолчанию). Байты копятся до разделителя `end`:

| end | разделитель |
| --- | --- |
| 0 | `\n`; `\r` отбрасывается, так что подходят и `\n`, и `\r\n` |
| 1 | `\r`; `\n` отбрасывается |
| 2 | первый символ `end_char`, например `;` |

Готовая строка (без разделителя) появляется на `line`, а `ready` становится true
на один цикл — по нему удобно записать строку в переменную (`var_set` с
`write_enable`) или разобрать её: «Сравнение строк», «Подстрока», «Строка → число».
За цикл выдаётся одна строка, следующая ждёт в буфере приёма.

`timeout` — для устройств без разделителя: если после последнего байта прошло
столько времени, накопленное тоже считается строкой. `max_len` ограничивает длину:
длинная строка выдаётся частями.

**По байту** (`mode = 1`): каждый цикл берётся один байт — `byte` (0…255) и
импульс `new`.

`available` — сколько байт ещё ждёт в буфере. Если он долго растёт, данные идут
быстрее, чем программа их забирает; увеличьте буфер приёма в настройках платы.

Удобно для отладки команд без второго устройства: выберите порт «USB» (`port = -1`),
наберите `SET 2.5` в консоли и смотрите, как меняется уставка.

```toml
[[block]]
id = "rx"
type = "uart_read"
uart = 2
end = 0
```
