# Масштабирование

Переводит сырое значение в физическую величину по двум точкам:
`in_min → out_min`, `in_max → out_max`. Обратный диапазон (out_min > out_max)
тоже работает.

Пример: датчик давления 0…10 бар на АЦП ESP32 (0…4095):

```toml
[[block]]
id = "bar"
type = "scale"
in_min = 0.0
in_max = 4095.0
out_min = 0.0
out_max = 10.0
```
