# Подстрока

Берёт часть строки: `len` байт начиная с `start` (счёт с 0); `len = -1` — до конца.
Если `start` за концом строки, выход пустой; если строка короче, берётся сколько есть.

Пример: из команды `"SET 25"` взять число — `start = 4`, `len = -1` даёт `"25"`,
дальше «Строка → число».

Позиции считаются в байтах: русская буква занимает 2 байта.

```toml
[[block]]
id = "arg"
type = "text_substring"
start = 4
```
