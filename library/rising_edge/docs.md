# Передний фронт

Выход `out` становится true на один цикл программы при переходе false → true входа `in`,
в остальное время он false. Удобно для счёта нажатий и действий «по событию».

До первого цикла вход считается false, поэтому если при включении питания
вход уже true, передний фронт сработает сразу.
