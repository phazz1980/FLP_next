# Символ из строки

Номер считается с нуля; за пределами строки символ пустой, код 0. Для русских букв (UTF-8) возьмётся один байт.

toml
[[block]]
id = "x"
type = "text_char"

## В модуле на плате (WASM)

Строка — буфер до 128 байт в памяти модуля; более длинный текст обрезается (в прошивке из скетча длина не ограничена). Строку пока нельзя передать на другой лист или в переменную.
