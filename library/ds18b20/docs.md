# DS18B20

Читает температуру с датчика DS18B20. Датчик подключается к выводу `pin`,
между линией данных и питанием 3,3 В нужен резистор 4,7 кОм.

Опрос не останавливает программу: блок запрашивает измерение и забирает
результат через `period`. До первого измерения `temp = 0`, `ok = false`.
Если датчик отвалился, `ok` становится false, а `temp` хранит последнее
удачное значение.

На одной шине может быть несколько датчиков — тогда на каждый свой блок
с тем же `pin` и разным `index`.

Нужны библиотеки OneWire и DallasTemperature — `flp build` ставит их сам.

```toml
[[block]]
id = "water"
type = "ds18b20"
pin = 4
```
