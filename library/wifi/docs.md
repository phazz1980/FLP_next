# Wi-Fi клиент

Подключает ESP32 к сети Wi-Fi и/или поднимает свою точку доступа. При обрыве
связи библиотека FLProg_Network сама переподключается.

Блок один на проект. Сетевые блоки (Modbus TCP) работают через него,
поэтому без блока Wi-Fi они не соберутся.

## Режим

0 — клиент (подключение к сети `ssid`), 1 — своя точка доступа `ap_ssid`,
2 — клиент и точка доступа одновременно. Режим задаётся параметром или,
с галочкой «Вход «Режим»», входом `mode`.

## Входы и выходы

Каждый вход и выход включается галочкой в свойствах блока; выключенных нет
ни на блоке, ни в коде прошивки.

| Порт | Тип | По умолчанию | Значение |
|---|---|---|---|
| вход `en` | bool | выкл. | true — Wi-Fi работает, false — радио выключено |
| вход `mode` | int | выкл. | режим, как выше (вне 0..2 — клиент) |
| выход `ready` | bool | вкл. | есть связь с сетью и получен адрес |
| выход `ap_ready` (на блоке «AP») | bool | выкл. | своя точка доступа работает |
| выход `address` (на блоке «IP») | string | вкл. | адрес ESP32 (`192.168.1.50`); в режиме точки доступа без клиента — её адрес; пустая строка без связи |
| выход `status` | int | выкл. | 0 выключен, 1 ожидание, 2 подключение, 3 готов, 4 переподключение, 5 ошибка |
| выход `error` | int | выкл. | 0 нет ошибки, 1 точка доступа не отвечает (таймаут), 2 сеть с таким SSID не найдена |

Включение и режим применяются, только когда меняются, так что вход можно
держать подключённым постоянно.

## Пароли

Пароли сети и своей точки доступа в файл проекта не записываются: программа
хранит их у себя отдельно для каждого SSID (`%APPDATA%\FLP_next\local.toml`)
и подставляет при сборке. Под блоком они показаны звёздочками. На другом
компьютере пароль надо ввести заново. Пароль точки доступа — не короче
8 знаков, пустой — открытая сеть.

Нужна библиотека из `Flprog_Network/Библиотека` в корне FLP_next: сборка
подключает её сама (другую папку можно задать переменной `FLP_ARDUINO_LIBS`).

Примеры: `examples/modbus_wifi`, `examples/wifi_modes` (все входы и выходы).
