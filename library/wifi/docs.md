# Wi-Fi клиент

Подключает ESP32 к сети Wi-Fi и/или поднимает свою точку доступа. При обрыве
связи библиотека FLProg_Network сама переподключается.

Блок один на проект. Сетевые блоки (Modbus TCP) работают через него,
поэтому без блока Wi-Fi они не соберутся.

## Режим

Режим выбирается списком в свойствах блока:

| Режим | Что работает | Настройки | Входы и выходы |
|---|---|---|---|
| Клиент | подключение к сети `ssid` | SSID, пароль, DHCP/адрес | ready, IP, status, error |
| Точка доступа | своя сеть `ap_ssid` | SSID и пароль точки | AP, IP, status |
| Клиент и точка доступа | обе сразу | все | все |
| Задаётся входом «Режим» | по входу `mode`: 0 клиент, 1 точка, 2 оба | все | вход «Режим» и все выходы |

Ненужные в выбранном режиме настройки, входы и выходы скрываются.

## Входы и выходы

Каждый вход и выход включается галочкой в свойствах блока; выключенных нет
ни на блоке, ни в коде прошивки.

| Порт | Тип | По умолчанию | Значение |
|---|---|---|---|
| вход `en` | bool | выкл. | true — Wi-Fi работает, false — радио выключено |
| вход `mode` | int | в режиме «Задаётся входом» | 0 клиент, 1 точка доступа, 2 оба (другое — клиент) |
| выход `ready` | bool | вкл. (режимы с клиентом) | есть связь с сетью и получен адрес |
| выход `ap_ready` (на блоке «AP») | bool | вкл. (режимы с точкой доступа) | своя точка доступа работает |
| выход `address` (на блоке «IP») | string | вкл. | адрес ESP32 (`192.168.1.50`); в режиме точки доступа без клиента — её адрес; пустая строка без связи |
| выход `status` | int | выкл. | 0 выключен, 1 ожидание, 2 подключение, 3 готов, 4 переподключение, 5 ошибка |
| выход `error` | int | выкл. (режимы с клиентом) | 0 нет ошибки, 1 точка доступа не отвечает (таймаут), 2 сеть с таким SSID не найдена |

Включение и режим применяются, только когда меняются, так что вход можно
держать подключённым постоянно.

## Пароли

Пароли сети и своей точки доступа в файл проекта не записываются: программа
хранит их у себя отдельно для каждого SSID (`%APPDATA%\FLP_next\local.toml`)
и подставляет при сборке. Под блоком они показаны звёздочками. На другом
компьютере пароль надо ввести заново. Пароль точки доступа — не короче
8 знаков, пустой — открытая сеть.

Нужна библиотека из `libs` в корне FLP_next: сборка
подключает её сама (другую папку можно задать переменной `FLP_ARDUINO_LIBS`).

Примеры: `examples/modbus_wifi`, `examples/wifi_modes` (все входы и выходы).

## Веб-страница и обновление прошивки

Пока включён параметр «Веб-страница» (по умолчанию да), блок поднимает страницу на порту 80:
IP, MAC, аптайм, дата сборки, состояние обновления (у Wi-Fi ещё уровень сигнала).

- «Загрузка прошивки» — на странице форма выбора `.bin`; файл уходит на порт 8080 и пишется
  прямо в память (`Update`), потом устройство перезагружается. Нужен `.bin` приложения
  (Скетч → Экспорт бинарного файла), не «merged».
- «Обновление по сети» — OTA библиотеки flprogNetwork (менеджер OTA, Arduino IDE).
- «Пароль OTA» общий для обоих способов; пустой — обновлять может любой в сети.
- Wi-Fi и Ethernet в одном проекте займут одни порты 80 и 8080: у одного из блоков страницу выключите.
