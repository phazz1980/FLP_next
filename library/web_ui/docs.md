# Веб-интерфейс

Блок включает на ESP32 страницу управления по адресу `http://<адрес платы>/`.

Что нужно: блок **Wi-Fi** с включённой веб-страницей и один блок «Веб-интерфейс» (он единственный).
Содержимое страницы — блоки группы «Веб-интерфейс»:

| Блок | Роль |
|---|---|
| Веб-кнопка | выход `true`, пока кнопка нажата |
| Веб-переключатель | выход держит состояние |
| Веб-ползунок, Веб-ввод числа | числовой выход (уставка); у ввода числа параметр «Целое число» делает выход целым (`int`) |
| Веб-ввод текста | строковый выход: имя сети, пароль, адрес брокера и т. п.; «Скрыть ввод» делает поле паролем (плата не отдаёт его обратно на страницу). Значение хранится до перезагрузки. Пример — `examples/net_setup` |
| Веб-индикатор, Веб-значение, Веб-шкала, Веб-текст | показывают сигнал со входа |
| Заголовок страницы | статичная надпись |

Расположение — сетка из 24 колонок (строка — 24 px): у каждого виджета параметры «Колонка», «Строка», «Ширина», «Высота».
Проще всего собрать страницу в конструкторе: `flp-web <проект>` → `http://127.0.0.1:8080/designer`
(перетаскивание, изменение размера, подписи, привязка входов к схеме, предпросмотр той же страницы,
которая попадает в прошивку).

Страница опрашивает `/ui/state` дважды в секунду; значения управляющих виджетов хранятся в ОЗУ
и после перезагрузки возвращаются к «Начальному». Пароль страницы (параметр «Пароль страницы») защищает значения и запись; пустой — вход свободный.

Виджет, добавленный в редакторе схемы, попадает в правую панель конструктора «Не размещённые» (строка 0); его перетаскивают на страницу или щёлкают по нему. Пока конструктор запущен, редактор сохраняет проект после каждой правки веб-виджетов.

**В модуле WASM** (лист собирается отдельным модулем, `flp gen-wasm`): страницу и сервер держит мастер-прошивка, модуль один раз передаёт раскладку, таблицу виджетов и пароль страницы, затем обновляет значения. Блок `web_ui` и виджеты стоят на одном листе; на плате не больше 32 виджетов, текст виджета до 128 байт. Страница идёт по интерфейсам, у которых в блоках «Wi-Fi» и «Ethernet» включена «Веб-страница». Пароль защищает чтение и запись; в модуле он лежит в данных модуля. «Веб-график» ведёт мастер: точку значения он записывает раз в заданный период и хранит до 120 точек, история сбрасывается при перезагрузке платы. Страница «Система» работает без формы загрузки прошивки. Форму сети («Веб-настройки сети») ведёт мастер: введённое сохраняется во флеш платы (Preferences), применяется блоками «Wi-Fi» и «Ethernet» вместо их полей и выдаётся на выходы блока; пароль на страницу не возвращается, пустой пароль оставляет сохранённый. Пример — `examples/web_wasm`.
