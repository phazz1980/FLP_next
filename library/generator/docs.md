# Генератор

Пока вход `en` true (или не подключён), выход `out` попеременно включается
на `time_on` и выключается на `time_off`. Каждый раз, когда `en` включается,
период начинается заново с включённого состояния.

```toml
[[block]]
id = "blink"
type = "generator"
time_on = "200ms"
time_off = "800ms"
```
