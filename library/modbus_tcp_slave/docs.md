# Modbus TCP Slave

Отдаёт по Modbus TCP четыре таблицы с адреса 0: регистры хранения (4x),
входные регистры (3x), катушки (0x) и дискретные входы (1x). Размеры таблиц
задаются в параметрах. Работает через блок «Wi-Fi клиент» (`net = "wifi"`)
или «Ethernet W5500» (`net = "ethernet"`) — нужный блок обязателен.

Значения в таблицы пишут и из них читают блоки «Запись Modbus» и «Чтение Modbus».
Один регистр — целое 16 бит; `float` занимает два регистра подряд.

Пример: `examples/modbus_wifi`.
