# Время по NTP

Получает точное время из интернета по протоколу SNTP (служба библиотеки FLProg_Network,
одинаковая для всех плат и сетей) и выдаёт его числами: часы, минуты, секунды, дата,
день недели, Unix-время и текст «ЧЧ:ММ:СС».

Блок один на проект. Нужен блок «Wi-Fi клиент» или «Ethernet W5500» — какой из них, выбирается
параметром **Сеть**. Запрос времени уходит, как только сеть поднялась. Часовой пояс и летнее
время блок прибавляет сам, системные часы (`time()`) он не заводит.

## Выходы

Каждый выход включается галочкой в свойствах блока; выключенных нет ни на блоке, ни в коде прошивки. По умолчанию включены `valid`, `hour` и `minute`.

| Выход | Тип | Значение |
|---|---|---|
| `valid` | bool | true, когда время получено с сервера |
| `age` | int | секунд с последней успешной синхронизации, -1 — ещё не было |
| `hour`, `minute`, `second` | int | часы 0–23, минуты и секунды 0–59 |
| `day`, `month`, `year` | int | день месяца, месяц 1–12, год |
| `weekday` | int | 1 понедельник … 7 воскресенье |
| `unix` | int | секунды с 1 января 1970 (UTC) |
| `text` | string | «ЧЧ:ММ:СС» |

Пока `valid` = false (нет сети или сервер не ответил), остальные выходы не меняются —
для расписаний всегда проверяйте `valid`, а недоверие к старому времени (долго нет связи) задайте по `age`, например «возраст больше суток». Значения обновляются раз в секунду.

## Параметры

- **Сеть** — Wi-Fi или Ethernet.
- **Сервер** — адрес NTP-сервера (по умолчанию `pool.ntp.org`).
- **Часовой пояс** — смещение от UTC в часах (Москва +3, дробные значения допустимы).
- **Период синхронизации** — как часто запрашивать время (по умолчанию 1 час, не меньше 15 секунд). Между запросами часы идут сами. Если запрос не удался, блок повторяет его через 30 секунд.
- **Летнее время** — прибавляет час.

Время хранится только в ОЗУ: после перезагрузки его надо получить заново.

```toml
[[block]]
id = "clock"
type = "ntp"
zone = 3.0
```
