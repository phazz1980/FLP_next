# Задержка выключения (TOF)

Пока вход `in` true, выход `out` тоже true. Когда вход падает в false, выход
остаётся включённым ещё `time` и потом выключается. Если вход снова включится
раньше, отсчёт сбрасывается.

Пример: вентилятор работает ещё 30 секунд после выключения нагрева.

```toml
[[block]]
id = "fan_delay"
type = "timer_off"
time = "30s"
```
