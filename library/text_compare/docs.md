# Сравнение строк

Проверяет строку `a` по образцу `b`:

| mode | условие | пример: `a = "SET 25"` |
| --- | --- | --- |
| 0 | равна | `b = "SET 25"` → true |
| 1 | содержит | `b = "25"` → true |
| 2 | начинается с | `b = "SET"` → true |
| 3 | заканчивается на | `b = "5"` → true |

`ignore_case = true` не различает регистр латинских букв: `"on"` равно `"ON"`.
Кириллица всегда сравнивается с учётом регистра.

Пустой образец содержится в любой строке, поэтому при `mode = 1…3` и `b = ""`
выход всегда true.

```toml
[[block]]
id = "is_on"
type = "text_compare"
b = "ON"
ignore_case = true
```
