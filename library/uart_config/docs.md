# Настройки UART

Настраивает UART (UART0 — только у ESP32-C3/S3, UART2 — у ESP32 и ESP32-S3) прямо на схеме — вместо раздела «UART» в окне
«Настройки МК». В свойствах блока: номер порта, скорость, формат (`8N1`, `8E1`…),
выводы RX, TX, DE/RE (RS-485) и буфер приёма. Блоки «Отправка в UART», «Чтение
из UART» и Modbus RTU на этом порту берут настройки отсюда, а в окне «Настройки МК»
порт показан как настроенный блоком.

Один порт настраивается в одном месте: либо в «Настройках МК», либо одним таким
блоком. Порт с этим блоком открывается при запуске, даже если других блоков на нём нет.

**Настройка на лету.** С `runtime = true` у блока появляются входы `new_speed`
(бод), `new_format` (строка, например `8E1`) и `apply`. По переходу `apply` в true:

- новый формат — порт перезапускается (`end`, `begin`) с этим форматом, скоростью
  со входа (или прежней) и выводами из свойств; несколько байт на линии при этом
  могут потеряться;
- только скорость — меняется без перезапуска (`updateBaudRate`);
- `new_speed = 0` не меняет скорость, пустой `new_format` не меняет формат.

Формат понимается в виде «биты данных, чётность N/E/O, стоп-биты»: от `5N1` до
`8O2`, регистр и пробелы по краям не важны. Непонятный формат порт не трогает, а
выход `ok` становится false. Выводы и буфер меняются только перепрошивкой. Выход
`baud` всегда показывает текущую скорость. На порту Modbus RTU настройки на лету
лучше не менять: библиотека Modbus считает паузы кадра по начальной скорости.

```toml
[[block]]
id = "port2"
type = "uart_config"
uart = 2
speed = 115200
rx = 16
tx = 17
```
