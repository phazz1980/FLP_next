# MQTT клиент

Подключает плату к MQTT-брокеру (Mosquitto, HiveMQ, Home Assistant и т. п.) через Wi-Fi или Ethernet.
Сам блок только держит соединение; данные отправляет «MQTT публикация», принимает «MQTT подписка».
Соединение восстанавливается автоматически. Нужен блок сети (`wifi` или `ethernet`).

- `net` — через какую сеть (wifi / ethernet), `broker` и `port` — адрес брокера;
- `client_id` — пусто: `flp-<номер чипа>`; `user` / `password` — авторизация (пароль в файл проекта не попадает);
- выходы: `connected` — есть соединение, `error` — код ошибки клиента.

Коды ошибки (выход `error`; клиент сам пробует подключиться снова, код остаётся до успешной операции):

| Код | Значение | Что проверить |
|---|---|---|
| 0 | нет ошибки | — |
| 1 | клиент занят | сообщение отправлено, пока уходило предыдущее |
| 2 | не задан брокер | параметр `broker` |
| 3 | не задан идентификатор клиента | `client_id` |
| 4 | исчерпан лимит сетевых служб | слишком много сетевых блоков |
| 5 | нет свободного сокета | меньше сетевых блоков или подписок |
| 6 | таймаут подключения | адрес и порт брокера, доступность сети |
| 7 | нет TCP-соединения с брокером | сеть (Wi-Fi/Ethernet), адрес, порт, брандмауэр |
| 8 | пакет слишком большой | пакет до 768 байт, топик до 127 символов |
| 9 | нарушение протокола MQTT | версия брокера (нужен MQTT 3.1.1) |
| 10 | брокер отказал в подключении | логин, пароль, уникальность `client_id` |
| 11 | брокер отклонил подписку | права на топик |
| 12 | таймаут ответа брокера | связь, `keepalive`, нагрузка на брокер |
| 13 | неподдерживаемая возможность | брокер ответил чем-то, чего клиент не умеет (QoS выше 0) |
| 14 | недопустимый топик | пустой, слишком длинный или с `+` / `#` в публикации |
| 15 | нет соединения с брокером | отправка до подключения: смотрите выход `connected` |
| 16 | логин или пароль не подходят | `user` и `password` |

Ограничения библиотеки: MQTT 3.1.1, QoS 0, число подписок задаёт `max_subscriptions` (по умолчанию 4), топик до 127 символов, пакет до 768 байт.
Если за один проход цикла пришло несколько сообщений, подписки увидят только последнее.

Пример: `examples/mqtt`.
