# Время цикла в порт

Блок включает измерение времени цикла и раз в `interval` печатает в последовательный порт
(115200 бод) отчёт: последний, средний и максимальный цикл `loop()`, максимальный период
между циклами, число циклов, свободную память и время каждого листа. Если есть фоновые
блоки, добавляется строка про ядро 0. Время — в микросекундах. Режим отладки не нужен.

В прошивке «С отладкой» текст не печатается (порт занят кадрами), цифры видны в окне диагностики.
Блок нужен один на схему; ни входов, ни выходов у него нет.

```toml
[[block]]
id = "cycle"
type = "cycle_report"
interval = "5s"
```
