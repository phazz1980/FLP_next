# MQTT публикация

Отправляет значение в топик через блок «MQTT клиент». Пока соединения нет, сообщение ждёт и уходит, как только оно появится.
Тип `value` берётся от подключённого выхода: bool уходит как `1`/`0`, число и строка — текстом.

`trigger`: по фронту `en`, по изменению значения (для float можно задать мёртвую зону) или периодически.
`retain` — брокер хранит последнее значение.

Пример: `examples/mqtt`.
