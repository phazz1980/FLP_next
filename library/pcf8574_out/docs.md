# PCF8574: выходы

Восемь дискретных выходов на микросхеме расширения PCF8574 или PCF8574A,
которая подключается к шине I²C. Так сделаны реле на платах Kincony и многих
других: микросхема стоит на двух проводах (SDA и SCL), а каналы `p0`…`p7`
управляют её выводами P0…P7.

- `address` — адрес микросхемы на шине, его задают перемычки A0–A2:
  0x20–0x27 у PCF8574 и 0x38–0x3F у PCF8574A. На одной шине может быть
  до 16 микросхем — на каждую свой блок.
- `sda`, `scl` — выводы шины. `-1` — выводы I²C по умолчанию для платы
  (у ESP32 DevKit это GPIO21 и GPIO22). Блоки на одной шине указывают одни и те же
  выводы, `Wire.begin` вызывается один раз для каждого типа блока.
- `inverted` — инвертировать выходы: `true` на входе даёт низкий уровень на выводе.
  Так включаются реле, у которых катушка подтянута к питанию, и светодиоды
  на плате, горящие от нуля.

Блок пишет в микросхему только при изменении каналов. Если микросхема не отвечает,
`ok = false`, а запись повторяется дважды в секунду, пока она не вернётся на шину.
Неподключённые каналы выключены.

Сторонние библиотеки не нужны: блок использует `Wire` из ядра ESP32.

```toml
[[block]]
id = "relays"
type = "pcf8574_out"
address = 36   # 0x24
sda = 4
scl = 15
inverted = true
```
