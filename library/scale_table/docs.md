# Нелинейное масштабирование

Выход считается по ломаной линии, заданной точками «вход:выход» через точку с запятой. Точки пишутся по возрастанию входа. Между точками выход меняется линейно, за крайними точками остаётся крайнее значение.

Пример: нелинейный датчик уровня.

```toml
[[block]]
id = "level"
type = "scale_table"
points = "0:0;50:20;100:100"
```
