# Задержка включения (Rust)

Тот же таймер TON, что и «Задержка включения», но логика написана на Rust (`src/block.rs`)
и собрана в `block.wasm` — один модуль и для симуляции на ПК, и для прошивки. Служит образцом блока на Rust/WASM.

Выход включается, когда вход непрерывно включён не меньше времени `time`; выключается сразу вместе со входом.

## Сборка модуля
Нужен `rustc` с целью `wasm32-unknown-unknown` (`rustup target add wasm32-unknown-unknown`).
Из папки блока: `build.cmd`. Интерфейс модуля — `help/10-block-editor.md` (раздел про `block.wasm`).

Шаблона `esp32.cpp.tmpl` у блока нет, поэтому прошивка строится из `block.wasm`: он переводится в C программой w2c2 (`block.wasm.c`) и вставляется в скетч. Пример проекта — `examples/wasm_ton`.
