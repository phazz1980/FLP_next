# Гистерезис

Выход включается, когда вход доходит до порога `on`, и выключается, когда
доходит до порога `off`; между порогами состояние сохраняется.

- `on > off` — включение при росте: вентилятор включить при 30 °C, выключить при 27 °C.
- `on < off` — включение при падении: обогрев включить при 18 °C, выключить при 21 °C.

```toml
[[block]]
id = "heater"
type = "hysteresis"
on = 18.0
off = 21.0
```
