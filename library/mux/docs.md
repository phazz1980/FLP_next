# Мультиплексор

Выбирает один из входов a…p по номеру `sel` (любое число, дробная часть отбрасывается). Число входов — параметр `count`.
Входы a…p принимают любой тип — логический, число, строку, — но все одного типа (`int` вместе с `float` дают `float`); выход того же типа.

```toml
id = "calc"
type = "mux"
```
