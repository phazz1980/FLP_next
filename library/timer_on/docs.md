# Задержка включения (TON)

Когда вход `in` становится `true`, начинается отсчёт. Если вход остаётся `true`
дольше `time`, выход `out` включается. Как только вход падает в `false`,
выход сразу выключается и отсчёт сбрасывается.

Переполнение `millis()` (раз в ~49 суток) обрабатывается корректно.

```toml
[[block]]
id = "delay"
type = "timer_on"
time = "5s"
```
