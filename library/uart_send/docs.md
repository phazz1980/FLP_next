# Отправка в UART

Отправляет в UART значение со входа `value`. Вход принимает любой тип — bool,
int, float или строку: что подключено, то и отправляется, отдельных входов под
типы нет.

**Как отправлять** (`send_as`):

| тип на входе | Текстом | Двоично |
| --- | --- | --- |
| bool | `1` / `0` | 1 байт: 1 / 0 |
| int | цифрами: `123` | по «размеру целого»: байт (0…255), int16 или long — младший байт первым |
| float | цифрами, `decimals` знаков после точки: `21.50` | float, 4 байта, младший первым |
| строка | как есть | её байты, без окончания |

Текстом после значения добавляется окончание `ending`: ничего, `\n` или `\r\n`.
Числа можно слать текстом сразу, без блока «Число → строка»; для сообщения из
нескольких частей подойдёт «Сцепление строк».

**Когда отправлять** (`trigger`):

- **по фронту en** (по умолчанию) — один раз при переходе `en` из false в true.
  Подключите генератор — получится отправка раз в период; кнопку — по нажатию;
- **каждый цикл, пока en** — цикл ESP32 короткий, так что это поток данных;
- **по изменению значения** — пока `en = true`, отправляется, только когда значение
  стало другим (первое после запуска — тоже). Для float есть `deadband`: изменение
  меньше этого не считается, иначе шум АЦП слал бы данные каждый цикл. Если
  сообщение не ушло (порт занят), блок пробует снова в следующем цикле.

`en` можно не подключать — тогда отправка разрешена всегда (для «по фронту» это
значит одну отправку после запуска).

Порт «USB» (`port = -1`): текст виден во вкладке «Монитор порта», а в отладке — в
консоли. Двоичные данные в USB лучше не слать: монитор покажет мусор. UART1 и UART2
(и UART0 у ESP32-C3/S3) настраиваются в «Настройках МК» или блоком «Настройки UART»; отправлять в один
порт могут несколько блоков.

Если буфер передачи UART почти полон (скорость мала для такого потока), сообщение
пропускается, а `sent` остаётся false — цикл программы не ждёт. Сообщение длиннее
64 байт может задержать цикл, пока уходит его хвост: 200 байт на 115200 бод — около 17 мс.

Проекты со старым видом блока (параметры `uart`, `mode`, `edge`, входы `text`, `lvalue`)
переводятся на новый при открытии. Число float, которое раньше уходило байтом или
int16, теперь уходит как float: для целого подайте на вход целый выход.

```toml
[[block]]
id = "report"
type = "uart_send"
port = -1
trigger = 2
```
