# Отправка в UART

Отправляет данные в UART, когда разрешено входом `en`:

- `edge = true` (по умолчанию) — один раз при переходе `en` из false в true.
  Подключите генератор — получится отправка раз в период; кнопку — по нажатию;
- `edge = false` — каждый цикл, пока `en = true`. Цикл ESP32 короткий, так что
  это поток данных: обычно нужен именно фронт.

Что отправлять (`mode`):

| mode | вход | что уходит |
| --- | --- | --- |
| 0 | `text` | строка и окончание `ending`: 0 — ничего, 1 — `\n`, 2 — `\r\n` |
| 1 | `value` | 1 байт: число, округлённое и ограниченное 0…255 |
| 2 | `value` | int16, 2 байта, младший первым |
| 3 | `value` | float, 4 байта, младший первым |

Строку собирают строковые блоки: «Число → строка», «Сцепление строк».

`uart = 0` — это USB: текст виден во вкладке «Монитор порта», а в отладке — в
консоли. Двоичные данные в USB лучше не слать: монитор покажет мусор. UART1 и UART2
настраиваются в настройках платы, отправлять в один порт могут несколько блоков.

Если буфер передачи UART почти полон (скорость мала для такого потока), сообщение
пропускается, а `sent` остаётся false — цикл программы не ждёт. Сообщение длиннее
64 байт может задержать цикл, пока уходит его хвост: 200 байт на 115200 бод — около 17 мс.

```toml
[[block]]
id = "report"
type = "uart_send"
uart = 0
```
