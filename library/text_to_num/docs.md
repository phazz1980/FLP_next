# Строка → число

Разбирает число из строки: `"21.5"`, `" -3 "`, `"1e3"`. Десятичная запятая тоже
понимается: `"21,5"` → 21.5. Пробелы по краям пропускаются.

Если в строке не число (`"abc"`, `"12кг"`, пустая строка), `ok = false`, а `out`
сохраняет последнее удачное значение: уставка не сбросится в 0 от случайного мусора.

```toml
[[block]]
id = "setpoint"
type = "text_to_num"
```
