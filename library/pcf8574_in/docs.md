# PCF8574: входы

Восемь дискретных входов на микросхеме расширения PCF8574 или PCF8574A,
которая подключается к шине I²C. Выходы блока `p0`…`p7` — состояние выводов
P0…P7, `ok` — ответила ли микросхема на последний опрос.

- `address` — адрес микросхемы на шине, его задают перемычки A0–A2:
  0x20–0x27 у PCF8574 и 0x38–0x3F у PCF8574A.
- `sda`, `scl` — выводы шины; `-1` — выводы I²C по умолчанию для платы.
- `inverted` — низкий уровень на выводе даёт `true`: так читаются оптопары
  и кнопки, замыкающие вывод на землю.
- `period` — как часто читать микросхему.

Вывод PCF8574 читается как вход, пока микросхема удерживает его в высоком уровне —
блок записывает в неё 0xFF при старте. Пока микросхема не отвечает, `ok = false`,
а выходы хранят последние прочитанные значения.

Сторонние библиотеки не нужны: блок использует `Wire` из ядра ESP32.

```toml
[[block]]
id = "inputs"
type = "pcf8574_in"
address = 34   # 0x22
sda = 4
scl = 15
inverted = true
```
