# MQTT подписка

Подписывается на топик через блок «MQTT клиент» и выдаёт последнее принятое сообщение.
`kind` — во что превращать текст: строка, целое, дробное или bool (`1`, `true`, `on` — true).
`received` — true в одном цикле после каждого сообщения. В шаблоне `+` — один уровень, `#` — весь остаток.

Библиотека держит не больше 4 разных подписок на проект.

Пример: `examples/mqtt`.
