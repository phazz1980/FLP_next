# Импульс (TP)

При переходе входа `in` из false в true выход `out` включается ровно на `time`,
сколько бы ни держался вход. Повторный фронт во время импульса не продлевает его.

Пример: короткое нажатие кнопки включает звонок на 2 секунды.

```toml
[[block]]
id = "bell"
type = "pulse"
time = "2s"
```
