# Сцепление строк

Склеивает строки по порядку `a`, `b`, `c`, `d`. Сколько входов — задаёт `count`
(2…4). Между частями ставится `separator`: при `separator = ";"` получится
`a;b;c`. Неподключённый вход — пустая строка.

```toml
[[block]]
id = "message"
type = "text_concat"
count = 3
separator = " "
```
