# Сцепление строк

Склеивает строки по порядку `a`, `b`, `c`, `d`. Сколько входов — задаёт `count`
(2…4). Между частями ставится `separator`: при `separator = ";"` получится
`a;b;c`. Неподключённый вход — пустая строка.

```toml
[[block]]
id = "message"
type = "text_concat"
count = 3
separator = " "
```

## В модуле на плате (WASM)

Строка — буфер до 128 байт в памяти модуля; более длинный текст обрезается (в прошивке из скетча длина не ограничена). Строку пока нельзя передать на другой лист или в переменную.
