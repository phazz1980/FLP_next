# Сохранение во флеш

По каждому переходу `save` из false в true записывает значение `in`
во флеш-память ESP32 (NVS) и выдаёт его на `out`. После перезагрузки
`out` сразу равен последнему сохранённому значению, а если ничего ещё
не сохраняли — `initial`.

Флеш изнашивается при частой записи (десятки тысяч циклов на ячейку),
поэтому сохраняйте по событию или редко — например, генератором раз в 10 минут,
а не каждый цикл.

Ключ в памяти — id блока (первые 15 символов), поэтому id сохраняемых
блоков должны различаться в первых 15 символах. Если переименовать блок,
сохранённое значение «потеряется».

```toml
[[block]]
id = "setpoint"
type = "flash_store"
initial = 22.0
```
