# Число → строка

Переводит число в текст: `21.53` при `decimals = 1` даёт `21.5`, при `0` — `22`.
`prefix` и `suffix` добавляются до и после числа, так одним блоком получается
готовое сообщение `T=21.5 °C`.

Целый вход тоже подходит (`int` сам становится `float`). Число переводится через
`float`, поэтому у целых больше 16 777 216 младшие цифры теряются.

```toml
[[block]]
id = "temp_text"
type = "num_to_text"
decimals = 1
prefix = "T="
suffix = " °C"
```
