# Modbus TCP Master

Опрашивает по Modbus TCP одно устройство (сервер) по `ip` и `port`: до четырёх ведомых
(Unit ID) на нём. С каждого ведомого циклически читаются таблицы с адреса 0:
регистры хранения (4x), входные регистры (3x), катушки (0x), дискретные входы (1x).
Размеры таблиц задаются параметрами. Работает через блок «Wi-Fi клиент» (`net = "wifi"`)
или «Ethernet W5500» (`net = "ethernet"`) — нужный блок обязателен.

Значения читают и пишут блоки «Чтение Modbus Master» и «Запись Modbus Master» с параметром
`master = "tcp"`; `slave` в них — один из Unit ID этого блока.
Один регистр — целое 16 бит; `float` занимает два регистра подряд.

Другое устройство (сервер) обычно собрано на блоке «Modbus TCP Slave».
